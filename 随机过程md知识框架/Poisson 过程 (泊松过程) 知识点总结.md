- # Poisson 过程 (泊松过程) 知识点总结

  ## 一、 概念 (补充)

  **计数过程**：随机过程 $\{N(t), t \ge 0\}$ 称为计数过程，如果 $N(t)$ 表示到时刻 $t$ 为止已发生的“事件”的总数。它满足：

  1. $N(t) \ge 0$ 且取值为整数；
  2. 若 $s < t$，则 $N(s) \le N(t)$；
  3. $N(t) - N(s)$ 表示在区间 $(s, t]$ 内发生的事件数。

  ## 二、 泊松过程的3种等价定义 (补充)

  图片中提到了3种等价定义，具体内容如下：对于计数过程 $\{N(t), t \ge 0\}$，以下三种定义是等价的：

  - **定义一 (微小增量定义)**：
    1. $N(0) = 0$；
    2. 过程具有**独立增量**（不相交时间段内发生的事件数相互独立）；
    3. 过程具有**平稳增量**（时间段内发生事件的概率仅与时间段长度有关）；
    4. $P(N(h) = 1) = \lambda h + o(h)$ （在极短时间 $h$ 内发生1次事件的概率近似与 $h$ 成正比）；
    5. $P(N(h) \ge 2) = o(h)$ （极短时间内发生2次及以上事件的概率极小，可忽略）。
  - **定义二 (分布定义)**：
    1. $N(0) = 0$；
    2. 过程具有**独立增量**；
    3. 任意长度为 $t$ 的区间内发生的事件数服从参数为 $\lambda t$ 的泊松分布，即 $N(t+s) - N(s) \sim P(\lambda t)$。
  - **定义三 (等待时间定义)**：
    1. $N(0) = 0$；
    2. 每次事件发生的**时间间隔**（发生间隔） $X_1, X_2, \dots$ 是独立同分布的随机变量，且均服从参数为 $\lambda$ 的指数分布，即 $X_i \overset{iid}{\sim} Exp(\lambda)$。

  ------

  ## 三、 性质

  ### 1. 任意时间段内发生次数

  在任意长度为 $t$ 的时间段内，事件发生的次数服从参数为 $\lambda t$ 的 Poisson 分布：

  $$N(t + s) - N(s) \sim P(\lambda t)$$

  *(注：由于平稳增量性，它在分布上等价于 $N(t)$)*

  ### 2. 发生间隔与发生时刻

  - **发生间隔 (Inter-arrival times)**：

    $\{X_i, i \ge 1\}$ 为独立同分布 (iid) 的随机变量，且服从指数分布：

    $$X_i \sim Exp(\lambda)$$

  - **发生时刻 (Arrival times)**：

    第 $n$ 次事件发生的时刻 $T_n = \sum_{i=1}^n X_i$。由于它是 $n$ 个独立的指数分布之和，因此服从 Gamma 分布（或称 Erlang 分布）：

    $$T_n \sim Gamma(n, \lambda)$$

    其概率密度函数为：

    $$f_{T_n}(t) = \frac{(\lambda t)^{n-1}}{(n-1)!}\lambda e^{-\lambda t}$$

  ### 3. 发生时刻的条件分布

  已知在 $[0, t]$ 时间段内共发生了 $n$ 次事件（即 $N(t) = n$），这 $n$ 次事件发生时刻 $T_1, T_2, \dots, T_n$ 的联合条件密度为：

  $$f(t_1, \dots, t_n | N(t) = n) = \frac{n!}{t^n}, \quad 0 < t_1 < \dots < t_n \le t$$

  **补充解释**：这表明，在已知 $[0, t]$ 内发生了 $n$ 次事件的条件下，这 $n$ 个发生时刻的分布，与在 $[0, t]$ 上独立均匀分布的 $n$ 个随机变量的**顺序统计量**（即排序后的结果）的分布是完全相同的。即无序的发生时刻条件服从 $UNIF(0, t)$。

  ### 4. Poisson 过程的合并 (Superposition)

  **性质**：两个独立的 Poisson 过程的独立和仍然是 Poisson 过程。

  - **补充**：若 $N_1(t)$ 的参数为 $\lambda_1$，$N_2(t)$ 的参数为 $\lambda_2$，且两者相互独立，则 $N(t) = N_1(t) + N_2(t)$ 是参数为 $\lambda_1 + \lambda_2$ 的 Poisson 过程。

  ### 5. Poisson 过程的随机分解 (Thinning/Splitting)

  随机分解分为常数概率和变时间概率两种情况：

  #### （一） 常数概率分解

  事件在每次发生时刻：

  - 以概率 $p$ 被独立划分为第 1 类；
  - 以概率 $q = 1 - p$ 被独立划分为第 2 类。

  若 $N_1(t), N_2(t)$ 分别表示在 $[0, t]$ 内发生的第 1、2 类事件次数，则：

  $$\Rightarrow \{N_1(t), t \ge 0\} \text{ 和 } \{N_2(t), t \ge 0\} \text{ 是参数分别为 } \lambda p \text{ 和 } \lambda q \text{ 的 Poisson 过程，且它们相互独立。}$$

  #### （二） 时间依赖概率分解

  若事件在 $T = s$ 时刻发生，则以概率 $p_i(s)$ 被独立划分为第 $i$ 类（$i = 1, 2, \dots, n$）。

  设 $N_i(t)$ 表示 $[0, t]$ 内发生的第 $i$ 类事件次数，则：

  $$\Rightarrow N_i(t) \sim P(\lambda t p_i)$$

  其中，$p_i$ 是概率 $p_i(s)$ 在时间区间 $[0, t]$ 上的时间平均值：

  $$p_i = \frac{1}{t} \int_0^t p_i(s) ds$$

  *(补充说明：这类分解得到的子过程在本质上是**非齐次泊松过程** (Non-homogeneous Poisson Process)，但在固定时刻 $t$ 的计数值仍服从泊松分布。)*
