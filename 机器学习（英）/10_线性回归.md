## 1. 模型在做什么

回归（Regression）预测数值目标，例如房价、二手手机价格；分类（Classification）预测类别，例如取消或不取消。

确定性函数关系（Functional relation）中，同一个输入直接决定输出；统计关系（Statistical relation）中，相同或相近输入仍可能有不同输出。线性回归用一条直线或一个平面概括总体趋势，允许残差存在。

单特征模型：

$$
\hat y=wx+b
$$

多特征模型：

$$
\hat y=w_1x_1+w_2x_2+\cdots+w_dx_d+b=\mathbf w^\top\mathbf x+b
$$

| 符号 | 含义 | 示例 |
|---|---|---|
| $x_j$ | 第 $j$ 个特征（Feature） | 房龄、收入 |
| $y$ | 实际目标（Target） | 实际房价 |
| $\hat y$ | 预测值（Prediction） | 预测房价 |
| $w_j$ | 系数／权重（Coefficient / Weight） | 特征变化对应的预测变化 |
| $b$ | 截距／偏置（Intercept / Bias） | 所有输入为 0 时的预测 |
| $e=y-\hat y$ | 残差（Residual） | 实际值减预测值 |

两个特征的预测面是平面，更多特征对应超平面（Hyperplane）。课程把多个输入特征称为 multivariate regression；其他教材也常称 multiple regression。

## 2. 向量、矩阵与维度

设训练集有 $n$ 行、$d$ 个特征，用列向量书写参数：

| 对象 | 数学形状 | 说明 |
|---|---|---|
| $\mathbf X$ | $n\times d$ | 每行是一条样本 |
| $\mathbf w$ | $d\times1$ | 每个特征一个权重 |
| $\mathbf y,\hat{\mathbf y}$ | $n\times1$ | 每条样本一个目标／预测 |
| $b$ | 标量 | 同一个截距加到所有行 |

因此 $\hat{\mathbf y}=\mathbf X\mathbf w+b$：$(n,d)@(d,1)\rightarrow(n,1)$。

为把截距一起写入正规方程，定义：

$$
\mathbf X_b=[\mathbf 1\ \mathbf X],\qquad
\boldsymbol\theta=[b,w_1,\ldots,w_d]^\top,\qquad
\hat{\mathbf y}=\mathbf X_b\boldsymbol\theta
$$

此时 $\mathbf X_b$ 为 $(n,d+1)$，$\boldsymbol\theta$ 为 $(d+1,1)$。课程有时仍把这个扩展参数向量写成 $\mathbf w$；本资料用 $\boldsymbol\theta$ 区分，避免漏掉截距。

NumPy 的 `(d,)` 是一维数组，严格说既不是二维行向量，也不是二维列向量；对它做 `.T` 仍是 `(d,)`。写手算矩阵与读代码时要分别核对形状。

```python
import numpy as np

X = np.array([[1., 2.], [3., 4.], [5., 6.]])
w = np.array([[2.], [-1.]])
b = 3.
X_b = np.c_[np.ones(len(X)), X]  # 添加截距列
theta = np.vstack([[[b]], w])
print((X @ w + b).ravel())       # [3. 5. 7.]
print(X_b.shape, theta.shape)    # (3, 3) (3, 1)
```

## 3. 三种误差指标

$$
MSE=\frac1n\sum_{i=1}^n(y_i-\hat y_i)^2
$$

$$
RMSE=\sqrt{MSE},\qquad MAE=\frac1n\sum_{i=1}^n|y_i-\hat y_i|
$$

| 指标 | 中文与英文 | 单位 | 侧重点 |
|---|---|---|---|
| MSE | 均方误差（Mean Squared Error） | 目标单位的平方 | 便于优化、求导 |
| RMSE | 均方根误差（Root Mean Squared Error） | 与目标相同 | 较大的误差权重更高 |
| MAE | 平均绝对误差（Mean Absolute Error） | 与目标相同 | 直接表示平均绝对偏差 |

三者都越小越好。因为平方根在非负范围单调递增，最小化 MSE 与最小化 RMSE 得到相同最优参数；MAE 的最优参数则不一定相同。

对同一批误差，$MAE\le RMSE$；所有误差的绝对值相等时取等号。RMSE 明显大于 MAE 提示部分误差偏大，但仍应看误差分布，不能只凭两个数定位异常样本。

**手算例题 A（自编）**：实际值 $y=[2,4,6]$，预测 $\hat y=[1,5,8]$。

1. 残差为 $[1,-1,-2]$。
2. $MSE=(1+1+4)/3=2$。
3. $RMSE=\sqrt2\approx1.414$。
4. $MAE=(1+1+2)/3=4/3\approx1.333$。

正负残差会抵消，不能用平均带符号残差代替上述误差指标。

## 4. 正规方程（Normal Equation）

对带截距的设计矩阵，普通最小二乘（Ordinary Least Squares, OLS）求解：

$$
\boldsymbol\theta^*=(\mathbf X_b^\top\mathbf X_b)^{-1}\mathbf X_b^\top\mathbf y
$$

矩阵形状按顺序为：$(d+1,d+1)@(d+1,n)@(n,1)\rightarrow(d+1,1)$。

**条件**：上述“显式求逆”写法要求 $\mathbf X_b$ 满列秩（Full column rank）。完全重复或完全线性相关的列，会使 $\mathbf X_b^\top\mathbf X_b$ 不可逆；$n\ge d+1$ 是必要条件，但不足以保证满秩。

这不等于“线性回归不能训练”。伪逆（Pseudoinverse）、奇异值分解（Singular Value Decomposition, SVD）等方法仍可求最小二乘解；参数可能不唯一。

`LinearRegression()` 通常无需手工加 1 列。它求解相同的最小二乘问题，普通稠密输入使用数值最小二乘求解器；不要把其内部实现背成“直接调用 `np.linalg.inv`”。

**手算例题 B（自编）**：$(x,y)=(0,1),(1,3)$。

$$
\mathbf X_b=\begin{bmatrix}1&0\\1&1\end{bmatrix},\quad
\mathbf X_b^\top\mathbf X_b=\begin{bmatrix}2&1\\1&1\end{bmatrix},\quad
\mathbf X_b^\top\mathbf y=\begin{bmatrix}4\\3\end{bmatrix}
$$

其逆为 $\begin{bmatrix}1&-1\\-1&2\end{bmatrix}$，因此 $\boldsymbol\theta=[1,2]^\top$，模型为 $\hat y=1+2x$。

**可选推导**：从 $J(\theta)=\frac1n\|\mathbf X_b\theta-\mathbf y\|^2$ 出发，令梯度 $\frac2n\mathbf X_b^\top(\mathbf X_b\theta-\mathbf y)=0$，得到正规方程组；只有满足可逆条件时，才进一步写成上面的逆矩阵公式。

## 5. 最小可运行代码

以下为自编模拟数据，只用于理解流程。训练均值基线（Mean baseline）必须使用 `y_train.mean()`。

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

rng = np.random.default_rng(409)
X = rng.uniform(0, 5, size=(100, 1))
y = 5 + 3 * X[:, 0] + rng.normal(0, 0.5, size=100)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=409
)
model = LinearRegression().fit(X_train, y_train)
pred = model.predict(X_test)
baseline = np.full(len(y_test), y_train.mean())  # 训练均值

print(model.intercept_, model.coef_)
print(np.sqrt(mean_squared_error(y_test, pred)))
print(mean_absolute_error(y_test, pred))
print(r2_score(y_test, pred))
print(np.sqrt(mean_squared_error(y_test, baseline)))
```

代码中 `y` 为 `(n,)`，所以单目标模型的 `coef_` 为 `(d,)`，`intercept_` 为标量；若 `y` 为 `(n,1)`，属性形状会相应不同，但模型含义一致。

## 6. 如何解释权重

假设 $\hat y=100+20x_1-5x_2$，价格单位为美元，$x_1$ 为存储容量单位数，$x_2$ 为使用年数。

- 在其他输入保持不变时，$x_1$ 增加 1，预测价格增加 20 美元。
- 在其他输入保持不变时，$x_2$ 增加 1，预测价格减少 5 美元。
- 截距 100 是所有输入为 0 时的预测；如果该组合不现实，截距不必有直接业务意义。
- 系数表达模型中的条件关联（Conditional association），不能直接解释为因果效应（Causal effect）。

输入单位不同，不能直接按原始系数绝对值排名重要性。若数值列已标准化，系数表示原特征增加一个训练集标准差时的预测变化，目标仍用原单位。

独热编码（One-hot encoding）中比较两个类别，可将其系数相减：例如“裂屏”系数 $-80$、“完好”系数 $20$，则其他条件相同下裂屏比完好低 $100$。保留所有类别又有截距时会存在冗余编码，单个类别系数不是相对一个被删除的参照组；类别差值更有解释性。

相关特征可能分摊或扰动系数。置换重要性（Permutation importance）衡量打乱某列后性能下降，与系数的正负方向是不同问题；它也不是因果结论。

## 7. 决定系数（R-squared）

对目标非恒定的一组评估样本：

$$
R^2=1-\frac{SSE}{SST}
=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}
$$

其中 $\bar y$ 是**当前被评分那组实际目标**的均值。测试集 R² 的分母使用测试集实际目标均值，这是指标定义；真实可部署的均值基线仍应使用训练集均值，两者不能混为一谈。

| 数值 | 解释 |
|---|---|
| $R^2=1$ | 该批样本预测完全正确 |
| $R^2=0$ | 平方误差与预测该批目标均值相同 |
| $R^2<0$ | 平方误差比该均值参照更大 |

例题 A 中 $\bar y=4$，$SST=4+0+4=8$，$SSE=6$，所以 $R^2=1-6/8=0.25$。若三条都预测 0，$SSE=56$，$R^2=1-56/8=-6$。

R² 不是分类准确率，也不是“25% 的预测正确”。测试 R² 可以为负，训练集表现良好也不保证测试集表现良好。

## 8. 统计输出与业务结果

**可选统计子页**：`statsmodels.OLS` 常需用 `sm.add_constant(X)` 显式加截距。输出中的 `coef` 是系数，`P>|t|` 是检验系数为 0 的 p 值，`[0.025, 0.975]` 是 95% 置信区间。

p 值是在零假设及统计模型假定下，出现至少这样极端检验统计量的概率；不是“零假设为真的概率”。显示 `0.000` 是舍入结果。统计显著（Statistically significant）不等于效果大、预测重要或存在因果。

95% 置信区间（Confidence interval）的长期含义是：重复抽样并用同一方法构造区间，约 95% 的区间覆盖固定的真实参数。考试优先会读系数、显著性与区间，不必扩展到完整推断课程。

作业 4 进一步强调：回归指标不能替代业务利润。以手机回收为例，报价 $o=r\hat y$，只有 $o\ge0.75y$ 时成交；成交利润为 $y-o$，未成交利润为 0。

例如实际价值 $100$、预测 $160$、报价比例 $0.75$：报价 $120$，成交后亏损 $20$。即使总体 R² 较高，某一类手机的系统性高估也可能导致亏损。用验证数据选择经营策略，最后用独立测试数据报告结果；反复看同一测试集挑报价，所得“最佳利润”会有选择偏差。

## 9. 易错点与纸笔自测

易错点：截距列漏加；把 `*` 当矩阵乘法；对 `(d,)` 转置后误认为是列向量；把 RMSE 说成平均带符号误差；不加条件地对奇异矩阵求逆；直接比较不同单位的系数；把 R² 当准确率或利润。

**先遮住答案完成以下 5 题。**

1. $n=50,d=4$，$\mathbf X_b^\top\mathbf X_b$ 是什么形状？
2. 所有误差绝对值都为 3，MAE、MSE、RMSE 各多少？
3. 标准化后的“房龄”系数为 2000，意味着每增加一年房价增加 2000 吗？
4. 测试集 $SSE=120,SST=100$，R² 为多少？
5. 两个特征列完全相同，正规方程的显式逆是否一定存在？

**答案**：1. `(5,5)`。2. `3、9、3`。3. 不是，是增加一个训练集房龄标准差时，其他输入不变的预测变化。4. $-0.2$。5. 不存在满列秩，不能用该显式逆；仍可用最小二乘数值方法求解。
