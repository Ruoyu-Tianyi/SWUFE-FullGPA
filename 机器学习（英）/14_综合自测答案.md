## 二、简答题参考要点

### S01

先确定正类和预测时间点，再明确预测结果触发的行动。列出 FP 与 FN 后果和成本，与当前规则比较；在未参与选择的数据上评估，再判断提升是否值得执行成本。不能从较高准确率直接跳到“可以超售”。

### S02

列表：可变有序序列，可保存待处理订单。元组：固定组合，可表达形状。字典：按唯一键映射值，可记录客户属性，保持插入顺序。集合：可变无序去重，可统计不同类别或做成员判断。索引、重复值和可变性要分开说明。

### S03

广播从右比较，最右的 5 与 3 不匹配。把门店系数改为 `(3,1,1)`，使其与门店轴对齐，并可沿周和产品轴扩展。广播由形状决定，不根据变量名字猜含义。

### S04

题目问全球酒店，分母必须覆盖全球酒店总体。变更表只是被筛选出的子集，用其行数得到的是“变更酒店内部升级比例”，与“全球酒店升级比例”不是同一个指标。

### S05

条形图比较类别汇总量，直方图看连续变量分布，箱线图概括中位数／四分位范围／异常值，散点图看两个数值变量关系。选择依据是问题，不是只根据图是否好看；图表不能自动证明因果。

### S06

基线提供简单可执行的参照，避免只报告一个孤立模型分数。未超过时先检查数据、划分、编码、指标和训练，再判断复杂模型是否必要；不能仅因为用了 ML 就认为比规则好。

### S07

填补与缩放参数会包含样本信息，使用留出数据估计会使评估偏乐观。每个 CV 训练折分别 fit 全部预处理，在其验证折只 transform；选定后再在全部开发数据 fit，最终测试只应用已有规则。

### S08

深度限制控制每条路径问多少问题，叶样本限制控制最终每个预测依赖多少训练记录。浅树仍可能隔离单行；叶样本数够大也不必树很浅。两者约束不同，需在验证中共同权衡。

### S09

训练学参数，验证选方法／设置，测试评估已经确定的方案。CV 各轮只使用开发数据的一部分来拟合；选定设置后重新利用全部开发样本得到最终模型，而非任意使用一折模型。

### S10

系数给出模型内的方向和单位变化效应，原始大小受量纲影响；不纯度重要性衡量树分裂累计贡献，没有方向；置换重要性衡量打乱列后表现下降，可用于多类模型。三者都依赖模型和数据，不自动代表因果。

### S11

它们可以优化同一线性模型的平方误差目标。相同输入和损失、无正则且充分收敛时，预测应接近。学习率、停止条件、缩放、随机性、默认正则化和秩不足可能造成差异。

### S12

Voting 合并多个模型预测；Bagging 用随机样本并行训练再组合，常降方差；Boosting 顺序添加修正，常降低偏差。若成员错误高度相关、概率不可靠、个体模型过弱或训练过拟合，集成未必改善测试表现。

## 三、综合题参考答案

### P01

第一处：先对全数据 fit_transform，再划分，测试信息已进入训练使用的缩放规则。第二处：用最终测试集比较深度并选择获胜者，测试集实际变成验证集。

正确流程：先锁定测试集 → 在开发数据中划验证／做 CV → 每个训练折拟合缩放和树 → 用验证分数选深度 → 全部开发数据重新拟合完整方案 → 测试一次。树通常不需要缩放；若使用也应放进该流程。

### P02

result 为 `[0,0,1,1]`。`range(1,5)` 包含 1–4。若函数只打印、没有 return，则列表收集的是 `[None,None,None,None]`，打印结果与返回结果不同。

### P03

- a：`(3,5)`，全部门店在第 2 周的各产品销量。
- b：`(5,)`，每个产品跨全部门店与周的总销量。
- c：`(1,4,1)`，第 2 家店每周的产品总销量，门店轴和被聚合产品轴均保留。

### P04

```python
result = (df.loc[df['country'] == 'China']
          .groupby('brand')['price'].mean()
          .sort_values(ascending=False).head(3))
```

每个输出值是该品牌在中国样本的平均价格；不是品牌中最贵的某个酒店，也不自动推广到数据没有覆盖的酒店。

### P05

共有 6 个 Axes，`ax[1,2]` 是第 2 行第 3 列。房价单变量分布优先看直方图，箱线图可补充分位信息；收入与房价关系用散点图。任意行号连线不能当作时间变化。

### P06

输出 `[0,1,0]`。规则用预订提前时间与押金类型组合预测，不需要在预测时知道真实取消标签。不能推出“强制缩短提前时间就一定减少取消”，规则建立在关联而非因果识别上。

### P07

$(14-10)/2=2$。单样本重新拟合会使自身均值为 14，标准差无法提供同样的训练尺度，也与已训练模型输入意义不一致。新类别应按训练编码规则处理，可用 `handle_unknown='ignore'` 令该组全零；这只保证格式兼容，不保证预测质量。

### P08

父节点熵为 1；A 的两子节点熵均约 0.811，因等大而加权熵约 0.811，IG≈0.189。B 的子节点熵都为 0，IG=1，因此当前应选 B。贪心当前最优不一般性保证全树全局最优；本例分裂后已经纯净。

### P09

总数 200；Accuracy=170/200=0.85；Precision=40/50=0.8；Recall=40/60≈0.667；F1=80/110≈0.727；成本=10×400+20×150=7000 美元。

参数组合 2×2×3=12，CV 拟合 12×5=60 次，加默认 refit 1 次，共 61 次。`best_score_` 是获胜组合平均 CV 分数，不是最后独立测试分数。

### P10

平方误差和=4+9+1=14。MSE=14/3≈4.667，RMSE≈2.160，MAE=6/3=2。真实值均值 20，总离差平方和=100+0+100=200，所以 R²=1−14/200=0.93。RMSE、MAE 与目标同单位，MSE 是平方单位，R² 无单位。盈利还依赖行动、误差方向和成本。

### P11

梯度 $2(0-3)=-6$，新 w=0.6，新损失 $(0.6-3)^2=5.76$。BGD 10 次更新，逐样本 SGD 1000 次。学习率任意增大可能使算法振荡或发散；“步大”不等于“更快收敛”。

### P12

硬投票选 B，两票；软投票平均 A 概率为 0.6，选 A。未入袋概率为 $(1-1/n)^n$，n 大时约 0.368。一行对某棵树是 OOB，不表示它没有被其他树用于训练；其 OOB 预测只聚合排除它的那些树。

## 四、单项选择题答案

| 编号 | 答案 | 解释 |
| --- | --- | --- |
| M01 | B | 有历史标签且预测取消/不取消，是监督分类；数字编码不改变目标含义 |
| M02 | C | `list.sort()` 原地排序，返回 `None`；`sorted(a)` 才返回新列表 |
| M03 | C | 从右比较形状，`(3,1,1)` 与门店轴对齐，其他两轴可广播 |
| M04 | B | iloc 第 3 个位置是 30；loc[2] 为 10；iloc[4] 越界；loc 标签切片含右端 |
| M05 | D | IQR=20，下围栏 −10，上围栏 70，80 在围栏之外 |
| M06 | C | 可部署的基线只能从训练目标学习常数；测试标签留作评估 |
| M07 | B | 填补、缩放、编码和模型必须作为整体在每个训练折内拟合 |
| M08 | D | 较大的叶最小样本数减少对少量记录的拟合；是否改善验证表现仍需检查 |
| M09 | C | sklearn 搜索最大化 scorer；−5 > −8 > −10 > −12，对应 RMSE=5 最低 |
| M10 | B | R²=1−SSE/SST；负值意味着 SSE>SST，不是负准确率 |
| M11 | C | 梯度为 2(0−3)=−6，新 w=0−0.1×(−6)=0.6 |
| M12 | B | 每行只能用未见过它的树产生 OOB 预测，不同样本对应的树集合不同 |

M10 的测试均值只是 R² 定义中的评价参照；不能因此在部署时使用未知测试标签建立基线。
