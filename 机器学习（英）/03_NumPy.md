本章目标：先判断形状（Shape），再判断数值；能把每个轴（Axis）和聚合结果翻译成业务含义。课程咖啡店练习使用 `sales.shape == (3,4,5)`，依次代表门店、周、产品。

## 1. 数组结构与创建

多维数组（N-dimensional Array, `ndarray`）使用统一的数据类型描述元素，支持向量化（Vectorization）运算。数值分析中通常使用数值 `dtype`，不要把 Python 列表与数组的运算规则混为一谈。

| 属性/操作 | 含义 | `a.shape == (2,3,4)` 时 |
|---|---|---|
| `a.ndim` | 轴的个数 | `3` |
| `a.shape` | 每个轴的长度 | `(2,3,4)` |
| `a.size` | 元素总数 | `2*3*4=24` |
| `a.dtype` | 元素的数据类型 | 如 `int64`、`float64` |
| `a.reshape(6,4)` | 在元素数不变时改变形状 | 仍为 24 个元素 |

```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.shape, a.ndim, a.size)    # (2, 3) 2 6
zeros = np.zeros((2, 3))         # 全零数组
ones = np.ones((2, 3))           # 全一数组
steps = np.arange(1, 6, 2)       # [1, 3, 5]，不含终点
points = np.linspace(0, 1, 3)    # [0., 0.5, 1.]，默认含终点
flat = a.reshape(-1)            # 自动推算唯一未知维度
```

文件中的数值可用 `np.loadtxt("numbers.txt", delimiter=",")` 读取，再按已知结构 `reshape`。不能把 24 个元素直接重塑成 `(5,5)`。

`(5,)` 是一维数组，既不是 `(1,5)` 行矩阵，也不是 `(5,1)` 列矩阵。`a.T` 交换二维数组的行列；一维数组转置后仍是一维，要得到列矩阵需 `a.reshape(-1,1)`。

## 2. 索引：一个整数会消去一个轴

数组用逗号区分不同轴，基本形式为 `a[轴0选择, 轴1选择, ...]`。整数选中一个位置并去掉该轴；切片保留该轴。

设 `sales.shape == (3,4,5)`：

| 选择 | 结果形状 | 业务含义 |
|---|---|---|
| `sales[1]` | `(4,5)` | 第 2 家门店，所有周和产品 |
| `sales[:,1]` | `(3,5)` | 第 2 周，所有门店和产品 |
| `sales[1,:,2]` | `(4,)` | 第 2 家门店，第 3 种产品的各周销量 |
| `sales[:,1:2,:]` | `(3,1,5)` | 第 2 周，保留周这个轴 |
| `sales[2,1:3,-2:]` | `(2,2)` | 第 3 家门店，第 2–3 周，最后两种产品 |
| `sales[0,3,2]` | 标量 | 第 1 家门店，第 4 周，第 3 种产品 |

切片仍是包含起点、不包含终点；负索引从末尾计数。不要把“第 2 周”写成索引 2，它的索引是 1。

布尔索引（Boolean Indexing）选择符合条件的元素：

```python
a = np.array([10, 20, 30, 40])
print(a[a >= 25])                  # [30, 40]
print(a[(a >= 20) & (a < 40)])      # [20, 30]
```

## 3. 逐元素运算、复制与矩阵运算

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(a + b)         # [5, 7, 9]
print(a * b)         # [4, 10, 18]
print(a ** 2)        # [1, 4, 9]
print(a @ b)         # 32：1*4 + 2*5 + 3*6
```

逐元素（Element-wise）运算按位置进行；`*` 不是矩阵乘法，`@` 才表示矩阵乘法/向量点积。二维矩阵 `(m,k) @ (k,n)` 得到 `(m,n)`，中间维度必须相同。这也是后续线性回归矩阵公式的基础。

NumPy 的**基本切片通常是视图（View）**，修改它会影响原数组；要独立数据应 `.copy()`。布尔索引、整数数组索引通常生成复制，不能把所有索引结果都当成视图。

```python
a = np.array([1, 2, 3, 4])
b = a[1:3]             # 共享原数组数据
b[0] = 99
print(a)               # [1, 99, 3, 4]
c = a[1:3].copy()      # 独立复制
c[0] = 0
print(a)               # 仍为 [1, 99, 3, 4]
```

## 4. 聚合：`axis` 指定“被合并掉的维度”

聚合（Aggregation）包括 `sum`、`mean`、`min`、`max`、`std` 等。`a.sum()` 默认汇总所有元素，**不指定 `axis` 并不等于默认按 `axis=0` 汇总**。

对于二维数组：`axis=0` 合并各行，保留每列一个结果；`axis=1` 合并各列，保留每行一个结果。“沿哪个方向”容易记错，直接检查被删除的形状位置更稳妥。

```python
a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.sum())                    # 21
print(a.sum(axis=0))              # [5, 7, 9]，形状 (3,)
print(a.sum(axis=1))              # [6, 15]，形状 (2,)
print(a.mean(axis=0))             # [2.5, 3.5, 4.5]
print(a.sum(axis=1, keepdims=True))  # [[6], [15]]，形状 (2, 1)
```

三维咖啡店案例：

| 表达式 | 结果形状 | 一个结果元素表示什么 |
|---|---|---|
| `sales.sum(axis=0)` | `(4,5)` | 某周某产品，所有门店合计 |
| `sales.sum(axis=1)` | `(3,5)` | 某门店某产品，全月合计 |
| `sales.sum(axis=2)` | `(3,4)` | 某门店某周，所有产品合计 |
| `sales.sum(axis=(1,2))` | `(3,)` | 每家门店全月总销量 |
| `sales.sum(axis=(0,1))` | `(5,)` | 每种产品全月总销量 |
| `sales.sum(axis=(0,2))` | `(4,)` | 每周所有门店、产品总销量 |

`keepdims=True` 将被汇总的轴保留为长度 1，常用于后续广播。`np.median(a)` 求中位数；`np.std(a)` 默认用总体标准差口径，即 `ddof=0`，与 Pandas `.std()` 默认口径不同。

## 5. 最大值与最大值位置

`max()` 返回数值，`argmax()` 返回最大值的位置；`argmin()` 同理。默认 `argmax()` 将整个数组按顺序展开后返回位置，指定 `axis` 则返回该轴上的位置；并列时返回首先出现的位置。

```python
a = np.array([[8, 2, 6], [3, 9, 1]])
print(a.max())              # 9
print(a.argmax())           # 4：展开后的索引
print(a.argmax(axis=0))     # [0, 1, 0]：每列最大值所在行
print(a.argmax(axis=1))     # [0, 1]：每行最大值所在列
```

业务写法：`products[sales.sum(axis=(0,1)).argmax()]` 返回总销量最高的产品名称；不能直接把 `argmax()` 的整数结果解释成销量。

## 6. 广播（Broadcasting）：从右向左比较

两数组逐元素运算时，从最右边的维度开始对齐。对应长度**相等，或至少一个为 1**，才可兼容；缺失的左侧维度视作 1。

```text
sales: (3, 4, 5)
price:       (5,)  → (1, 1, 5) → 可广播，结果 (3, 4, 5)
cost:        (3,)  → (1, 1, 3) → 末轴 5 与 3 不兼容
cost.reshape(3,1,1)           → 每门店一个系数，兼容
```

数组广播不是“看到相同数字就自动找到对应轴”。`price` 对齐末轴产品维度；门店系数必须显式放在门店轴上。

```python
np.random.seed(409)
sales = np.random.randint(20, 80, size=(3, 4, 5))
price = np.array([3.5, 3.0, 4.5, 6.5, 2.0])
cost = np.array([1.0, 1.2, 0.9])

revenue = sales * price                 # 数量 × 对应产品单价
store_units = sales.sum(axis=(1, 2))    # [934, 985, 1012]
store_revenue = revenue.sum(axis=(1, 2)) # [3628., 3881.5, 3902.5]
adjusted = sales * cost.reshape(3, 1, 1)
```

本例 `cost` 是课程给定的门店系数练习。`adjusted` 的业务含义由系数定义决定，不能仅凭变量名就称其为利润；利润还需要成本金额等信息。

销量最高不等于收入最高，收入最高也不等于利润最高。课堂数据中 Cookie 销量最高、Sandwich 收入最高，说明选择指标前必须明确问题。

## 7. 纸笔例题与解答

**题目。** `x=np.array([[2,4,6],[1,3,5]])`，`p=np.array([10,20,30])`。求 `(x*p).sum(axis=1)`，并写出中间和最终形状。

**解答。** `x` 为 `(2,3)`，`p` 的 `(3,)` 对齐最后一轴，乘积为 `[[20,80,180],[10,60,150]]`，形状 `(2,3)`。沿 `axis=1` 合并产品轴，得到 `[280,220]`，形状 `(2,)`。若行代表门店，这就是每店收入。

## 8. 易错点与自测

常见错误：把 `size` 当行数；把 `(n,)` 当列矩阵；把 `axis=0` 当“保留轴 0”；把最大值位置当最大值；基本切片修改后忘记原数组同步变化；广播时从左对齐。

1. `(3,4,5)` 有几个轴、多少元素？
2. `sales[:,1:2,2]` 的形状是什么？
3. `sales.mean(axis=(0,2), keepdims=True)` 的形状是什么？
4. `(4,1)` 与 `(3,)` 相加结果形状是什么？
5. 要计算每周收入，怎样从 `revenue` 汇总？

**简答：** 1. 3 个轴、60 个元素。2. `(3,1)`。3. `(1,4,1)`。4. `(4,3)`。5. `revenue.sum(axis=(0,2))`，形状 `(4,)`。
