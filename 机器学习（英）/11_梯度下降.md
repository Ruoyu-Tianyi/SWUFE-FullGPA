# 11 梯度下降（Gradient Descent）

[返回复习导航](00_复习导航.md) · 上一章：[线性回归](10_线性回归.md) · 下一章：[集成学习](12_集成学习.md)

> 复习目标：分清模型和训练算法，手算一次参数更新，比较 BGD、SGD 与 mini-batch，并读懂学习率、迭代轮数、停止条件和标准化代码。

## 1. 模型、损失和训练算法

这三个问题要分开回答：

| 问题 | 本章答案 |
|---|---|
| 用什么形式预测？ | 线性回归模型：$\hat y=\mathbf w^\top\mathbf x+b$ |
| 怎样衡量拟合不好？ | 损失函数（Loss function）：MSE |
| 怎样找到参数？ | 正规方程或梯度下降等优化算法（Optimization algorithm） |

梯度下降不是一种回归模型。它通过反复调整参数来降低损失；同一种模型可以用不同算法训练，同一种优化算法也可以训练不同模型。

梯度（Gradient）收集损失对每个参数的偏导数，指向局部最陡上升方向，所以更新时沿**负梯度**方向走：

$$
\boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta\nabla J(\boldsymbol\theta_t)
$$

$\eta>0$ 是学习率（Learning rate），决定步长；$t$ 是更新步数。

- 某个偏导数为正，该参数本步减小。
- 某个偏导数为负，该参数本步增大。
- 偏导数为零，该方向本步不动；“梯度为零必为全局最小”不是对任意损失都成立。

线性回归的 MSE 对参数是凸函数（Convex function）；合适学习率下可收敛到全局最小。若设计矩阵不满列秩，最优参数可能不唯一。对非线性模型，MSE 不一定是凸函数，零梯度还可能对应鞍点等情况。

## 2. 线性回归 MSE 的梯度

本章用误差 $r_i=\hat y_i-y_i$，即**预测减实际**；上一章残差写作 $e_i=y_i-\hat y_i$。平方损失不受符号影响，但求导时必须保持一致。

$$
J(\mathbf w,b)=\frac1n\sum_{i=1}^n(\mathbf w^\top\mathbf x_i+b-y_i)^2
$$

$$
\frac{\partial J}{\partial w_j}=\frac2n\sum_{i=1}^n r_ix_{ij},\qquad
\frac{\partial J}{\partial b}=\frac2n\sum_{i=1}^n r_i
$$

权重偏导数是“误差 × 对应特征”的平均再乘 2；截距相当于一个值恒为 1 的特征。

把截距并入参数，令 $\mathbf X_b=[\mathbf1\ \mathbf X]$、$\boldsymbol\theta=[b,w_1,\ldots,w_d]^\top$，则：

$$
\nabla J(\boldsymbol\theta)=\frac2n\mathbf X_b^\top(\mathbf X_b\boldsymbol\theta-\mathbf y)
$$

形状核对：$(d+1,n)@(n,1)\rightarrow(d+1,1)$，梯度形状必须与参数相同。

某些教材把损失定义为 $\frac1{2n}\sum r_i^2$，梯度就没有前面的 2；应先看损失定义，再套梯度，不能混用。

## 3. 一次 BGD 手算（自编）

两条数据：$(x,y)=(1,3),(2,5)$；初始 $b=0,w=0$；学习率 $\eta=0.1$。

**第一步：用同一组旧参数预测所有行。**

| 行 | $x$ | $y$ | $\hat y$ | $r=\hat y-y$ | $rx$ |
|---|---:|---:|---:|---:|---:|
| 1 | 1 | 3 | 0 | −3 | −3 |
| 2 | 2 | 5 | 0 | −5 | −10 |

**第二步：求梯度。**

$$
\frac{\partial J}{\partial b}=\frac22(-3-5)=-8,\qquad
\frac{\partial J}{\partial w}=\frac22(-3-10)=-13
$$

**第三步：同时更新。**

$$
b_{new}=0-0.1(-8)=0.8,\qquad
w_{new}=0-0.1(-13)=1.3
$$

新预测为 $[2.1,3.4]$，MSE 从 $(9+25)/2=17$ 降至 $(0.9^2+1.6^2)/2=1.685$。

“同时”指两个梯度都依据旧的 $b,w$ 计算。不能先更新 $b$，再用新 $b$ 计算同一步的 $w$ 梯度。

## 4. BGD、SGD 与 mini-batch

步（Step）是一次参数更新；轮（Epoch）是一次遍历训练数据。假设每轮恰好遍历 $n$ 行，mini-batch 大小为 $B$，最后一批不足 $B$ 也保留：

| 方法 | 一次更新用几行 | 每轮更新数 | 典型特点 |
|---|---:|---:|---|
| 批量梯度下降（Batch GD, BGD） | 全部 $n$ 行 | 1 | 梯度稳定，每次更新成本高 |
| 随机梯度下降（Stochastic GD, SGD） | 1 行 | $n$ | 单步便宜，方向有噪声 |
| 小批量梯度下降（Mini-batch GD） | $B$ 行 | $\lceil n/B\rceil$ | 兼顾计算效率与稳定性 |

例如 $n=100$、10 轮：BGD 更新 10 次，SGD 更新 1000 次；若 $B=20$，mini-batch 更新 50 次。

课程手写 SGD 示例每轮有放回随机抽取 $n$ 次，因此某行可能被重复抽到，另一些行没被抽到；这里“一轮”按 $n$ 次抽取计。先打乱顺序再逐行遍历则会让每行每轮恰好出现一次。

单样本 SGD 梯度为：

$$
\mathbf g_i=2\mathbf x_{b,i}(\mathbf x_{b,i}^\top\boldsymbol\theta-y_i)
$$

BGD 是在**同一参数点**平均所有单行梯度；SGD 每处理一行就改变参数，因此跑完一轮通常不等于做一次 BGD。

**接上例，顺序处理第 1 行再第 2 行。** 第 1 行梯度为 $(-6,-6)$，更新后 $(b,w)=(0.6,0.6)$。第 2 行的新误差为 $0.6+2(0.6)-5=-3.2$，梯度为 $(-6.4,-12.8)$，再更新得 $(b,w)=(1.24,1.88)$，不同于 BGD 的 $(0.8,1.3)$。

## 5. 学习率、缩放与停止

学习率太小会收敛慢；太大可能在谷底两边震荡甚至发散。增加轮数不能修复一个持续发散的学习率。

学习率调度（Learning schedule）让步长随训练过程变化；退火（Annealing）通常指逐渐减小学习率，减少接近最优点时的跳动。SGD 固定步长时可能一直在最优点附近波动，单步损失不必单调下降。

特征缩放（Feature scaling）使不同量纲的特征更可比，改善损失面的形状，有助于 GD 更稳定、更快地优化。

$$
z_j=(x_j-\mu_j)/\sigma_j
$$

`StandardScaler` 的均值与尺度必须从训练数据学习；在交叉验证（Cross-validation）中应置于流水线（Pipeline），在每个训练折内拟合。标准化不保证原分布变成正态分布。

两种停止条件不要混淆：

- 课程手写 BGD：可在 $\|\nabla J\|<\epsilon$ 时停止，另设最大轮数上限。
- `SGDRegressor`：`max_iter` 是最大训练轮数；`tol` 默认用于检查若干轮内损失改善是否足够，不是直接比较梯度范数。`early_stopping=True` 时还涉及验证得分。

默认 `n_iter_no_change=5` 表示连续若干轮改善不足后停止；`n_iter_` 是实际运行轮数，可能小于 `max_iter`。[官方参数说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.SGDRegressor.html)

## 6. 可运行的 BGD 小例子

以下完整程序对应手算例题。线性回归可以从 0 初始化；随机初始化不是这里的必要条件。

```python
import numpy as np

X = np.array([[1.], [2.]])
y = np.array([[3.], [5.]])
X_b = np.c_[np.ones(len(X)), X]
theta = np.zeros((2, 1))          # 顺序为 b、w
eta = 0.1

for epoch in range(1000):
    error = X_b @ theta - y       # 预测减实际
    gradient = 2 / len(X) * X_b.T @ error
    theta = theta - eta * gradient
    if np.linalg.norm(gradient) < 1e-8:
        break

print(theta.ravel())              # 约为 [1. 2.]
print(np.mean((X_b @ theta - y) ** 2))
```

**这段循环如何对应前面的手算？** 为便于理解，把两行数据看成两个广告方案：`x` 是投入，`y` 是销售额；数字与单位仅用于教学。开始 `theta=[0,0]`，两行都预测 0，因此必须根据误差调整截距与斜率。

| 第一轮代码 | 实际得到什么 | 作用 |
|---|---|---|
| `X_b @ theta` | `[[0],[0]]`，形状 `(2,1)` | 对两条样本分别预测 |
| `error = ... - y` | `[[-3],[-5]]` | 保留每条样本的预测误差 |
| `X_b.T @ error` | `[[-8],[-13]]` | 将样本误差按每个参数的影响汇总 |
| `2 / len(X) * ...` | 本例系数为 1，梯度仍为 `[[-8],[-13]]` | 对应 MSE 的梯度定义 |
| `theta - eta * gradient` | `[[0.8],[1.3]]` | 同时得到新截距与新斜率 |

第二轮继续用新参数对**同样两条训练样本**预测，再算误差；不是每一轮新增一条数据，也不是每一轮增加一个特征。循环结束输出的是学到的参数，预测新投入值还需代入 `b+w*x`。

代码先计算完整 `gradient`，再更新完整 `theta`，自然实现同一步的同时更新。这里的 `theta` 与 `y` 都是二维列向量，避免 `(n,1)-(n,)` 意外广播成 `(n,n)`。

## 7. sklearn：SGD 与线性回归对照

`SGDRegressor(loss="squared_error")` 拟合线性预测函数。若要与无惩罚 OLS 对照，应显式设置 `penalty=None`；默认 `penalty="l2"` 会增加正则项（Regularization term），优化目标已有变化。作业 4 按要求使用默认构造器时保留该默认，不应偷偷改写作业设置。[官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.SGDRegressor.html)

以下自编数据示例可独立运行；两者应得到接近的结果，不要求有限步 SGD 的小数逐位相同。

```python
import numpy as np
from sklearn.linear_model import LinearRegression, SGDRegressor
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(409)
X = rng.normal(size=(100, 2))
y = 5 + 3 * X[:, 0] - 2 * X[:, 1]
ols = LinearRegression().fit(X, y)
sgd = Pipeline([
    ("scale", StandardScaler()),
    ("model", SGDRegressor(
        loss="squared_error", penalty=None,
        max_iter=10000, tol=1e-8,
        eta0=0.01, random_state=409
    )),
]).fit(X, y)
print(np.max(np.abs(ols.predict(X) - sgd.predict(X))))
```

这里训练集对照是为了检验优化效果；实际比较泛化性能还需训练／测试拆分。OLS 在原始坐标下的系数与标准化后 SGD 的系数不能直接逐项比较，先统一特征尺度或比较预测值。

`eta0` 在默认 `learning_rate="invscaling"` 下是初始步长，后续还会衰减；显式设 `learning_rate="constant"` 才是恒定步长。参数值大并不自动表示模型更复杂或预测更准确。

## 8. 作业 4 的网格搜索如何读

SGD 搜索 `max_iter` 两个值、`tol` 两个值、`eta0` 两个值，共 $2\times2\times2=8$ 组。5 折交叉验证需要 40 次折内训练，默认再对最佳参数完整重拟合 1 次，共 41 次。

如果流水线的模型步骤叫 `sgd_reg`，参数键必须写成 `sgd_reg__eta0` 等；双下划线连接步骤名和参数名。

作业使用 `scoring="neg_root_mean_squared_error"`。搜索器始终选择**得分最大**者，因此 $-20$ 优于 $-50$，对应 RMSE 20 优于 50。若不指定 `scoring`，回归器默认 `score` 通常是 R²，不能擅自认为搜索在优化 RMSE。

SGD 调参主要解决收敛和所选目标的优化问题；若线性模型无法表达弯曲关系，继续增加轮数也不会自动让预测函数变成曲线。

## 9. 易错点与纸笔自测

易错点：把 GD 当模型；把梯度上升写成下降；漏掉损失定义中的 2；先更新一个参数再算同一步另一个梯度；把 epoch 当单样本更新；以为所有 MSE 都凸；以为增大 `max_iter` 必定改善；混淆标准化坐标与原坐标系数。

**先作答，再看答案。**

1. 旧参数 $\theta=[1,2]^\top$，梯度 $[4,-6]^\top$，$\eta=0.1$，新参数是什么？
2. 1000 行数据，batch size 为 128，mini-batch 每轮保留最后一批，有多少次更新？
3. SGD 某一步的全训练集损失上升，是否足以证明程序写错？
4. 两个设置均用线性预测函数，一个 OLS、一个默认 `SGDRegressor`，是否必定得到完全相同的最优参数？
5. `best_score_=-80` 表示“RMSE 为负数”吗？

**答案**：1. $[0.6,2.6]^\top$。2. $\lceil1000/128\rceil=8$。3. 否，单行随机梯度有噪声。4. 否；默认 SGD 有 L2，有限迭代与停止条件也影响结果。5. 否，负号是评分约定，对应平均交叉验证 RMSE 约为 80。
