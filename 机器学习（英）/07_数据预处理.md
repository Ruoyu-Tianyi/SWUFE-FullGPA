本章四条主线是缺失值（Missing Values）、异常值（Outliers）、标准化（Standardization）和类别编码（Categorical Encoding）。所有操作都要回答：为什么这样处理、从哪些数据学习规则、预测新样本时怎样保持一致。

## 1. 缺失值：先检查，再决定

缺失率是某列缺失数量除以样本总数。`isna()` 与 `isnull()` 在这里作用相同；字符串 `"?"`、`"unknown"` 不会自动成为缺失值，需要按数据定义清理。

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "age": [20.0, 30.0, np.nan, 40.0],
    "city": ["A", "B", np.nan, "A"],
})
print(df.isna().sum())   # 两列都缺 1 个
print(df.isna().mean())  # 两列缺失率都为 0.25
```

| 方法 | 适用判断 | 主要代价或限制 |
|---|---|---|
| 删除列 | 缺失很多且信息价值有限 | 丢失整列信息，不能只看缺失率 |
| 删除行 | 少量行缺失，且删除不会明显改变样本结构 | 减少数据，可能造成选择偏差 |
| 均值填充（Mean Imputation） | 数值列，均值有代表性 | 容易受极端值影响 |
| 中位数填充（Median Imputation） | 数值列，分布偏斜或有极端值 | 不能恢复真实个体差异 |
| 众数填充（Most-Frequent Imputation） | 数值或类别列 | 增加最常见取值的比例 |
| 常数填充（Constant Imputation） | 有明确业务含义的占位值 | 如用 0，须区分“真实为零”和“未知” |
| 前向/后向填充（Forward/Backward Fill） | 顺序有意义且相邻值适合沿用 | 不能随意跨客户、跨实体填充 |

填充值是估计，不等于真实值；填充后缺失数变成 0，不代表数据问题完全解决。

```python
# 只演示各语句的作用，不要求依次执行
rows_kept = df.dropna(subset=["age"])
column_removed = df.drop(columns=["city"])
filled = df.assign(age=df["age"].fillna(df["age"].median()))
```

`dropna()` 默认会删除含有任意缺失值的行；删除后如果特征 `X` 和目标 `y` 不同步，可能发生样本错配。应保留一致的行标识与索引。

## 2. 拟合与转换：训练数据决定规则

拟合（Fit）学习数据相关的参数；转换（Transform）使用已学到的参数处理数据。

| 预处理器 | `fit` 学到什么 | `transform` 做什么 |
|---|---|---|
| 填充器（Imputer） | 每列均值、中位数或众数 | 用这些值补缺失 |
| 标准化器（Scaler） | 每列均值、标准差 | 按同一尺度转换 |
| 编码器（Encoder） | 已见类别与输出列映射 | 把新样本映射到相同列空间 |

**先划分数据，再仅在训练部分拟合。** 验证集、测试集使用同一个已拟合的预处理器。交叉验证中，每一折都必须只用该折的训练部分重新拟合预处理器。

如果先对全体数据填充、标准化，再做交叉验证，验证折的信息已进入预处理参数，形成数据泄漏（Data Leakage）。即使操作没用到目标值，也可能使评估偏乐观。

```python
from sklearn.impute import SimpleImputer

train_age = np.array([[10.0], [20.0], [np.nan], [30.0]])
test_age = np.array([[np.nan], [100.0]])

imputer = SimpleImputer(strategy="mean")
train_filled = imputer.fit_transform(train_age)
test_filled = imputer.transform(test_age)
print(imputer.statistics_)  # [20.]
print(test_filled.ravel())  # [20., 100.]
```

测试集的 100 不参与计算填充值。课程早期决策树示例为了演示曾使用测试集自身的均值；完整建模时采用这里的训练统计原则。

字符串类别不能用默认的均值填充器。应明确写成：

```python
cat_imputer = SimpleImputer(strategy="most_frequent")
cat_values = cat_imputer.fit_transform(df[["city"]])
```

**追踪填补前后的一条客户记录。** 把本节 `train_age` 理解为四位历史客户的年龄列，第四位为 30 岁，第三位未填；`test_age` 是两位待预测客户，其中第一位未填、第二位为 100 岁。训练数据的已知年龄为 10、20、30，故只学到一个填充值 20。输出仍为四行训练数据、两行测试数据，行序不变，仅缺失位置被替换。

`fit_transform(train_age)` 同时做“学规则”和“应用规则”；`transform(test_age)` 只做后者。填补器没有推断出新客户实际 20 岁，它只给模型提供按既定规则补齐的输入。

## 3. 异常值：偏离常态不等于错误

异常值可能来自单位错误、录入错误，也可能是真实的高价值客户或极端事件。删除前应先解释其来源及业务意义。

标准分数（Z-score）为：

$$z=\frac{x-\mu}{\sigma}.$$

`z=2` 表示高于均值两个标准差；`z=-1` 表示低于均值一个标准差。课堂用 $|z|\geq 3$ 作为一种异常识别规则，它是启发式标准，并非所有分布都适用的真理。

```python
s = pd.Series([10.0, 12.0, 14.0, 16.0])
z = (s - s.mean()) / s.std(ddof=0)
suspect = z.abs() >= 3
```

**计算口径提醒：** Pandas 的 `.std()` 默认 `ddof=1`；NumPy 的 `np.std()` 默认 `ddof=0`。小样本时结果可能明显不同。题目给定标准差时直接使用给定值；需要复现计算时统一口径。

箱线图（Box Plot）的常见异常界限：

$$IQR=Q_3-Q_1,$$

$$\text{下界}=Q_1-1.5IQR,\qquad \text{上界}=Q_3+1.5IQR.$$

不是“中位数上下各 $1.5IQR$”。箱须通常画到界限以内最远的实际观测值，不一定正好画到公式计算出的界限。

课堂示范删除异常值后重新计算 z-score，是因为数据的均值和标准差已改变。不能由此推导出“应反复删除，直到所有点都合格”；反复筛选可能持续损失真实样本。

建模时也不能为了得到好看的测试分数，看到预测困难的测试点就删去。若训练数据确需过滤，规则应有业务依据，并保持 `X` 与 `y` 对齐。

## 4. 标准化：统一尺度，不改变分布形状

标准化后的训练特征通常均值为 0、方差为 1；它**不会自动把偏斜分布变成正态分布（Normal Distribution）**。常数列无法除以非零标准差，库会作相应处理；不要把“所有列方差必为 1”当作无条件结论。

为什么要标准化：年龄、收入、面积的量纲和数量级不同，可能影响梯度下降的优化速度，也会影响依赖距离或系数尺度的算法。

决策树通常不需要标准化，因为对一个特征作保持次序的线性变换不会改变可切分的样本次序。课程流水线保留标准化，是为了展示通用预处理结构。

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
train_z = scaler.fit_transform(train_filled)
test_z = scaler.transform(test_filled)
```

沿用上面的年龄数据，填补后的训练列是 `[10,20,20,30]`，均值为 20，总体标准差约 7.071。因而测试中的缺失年龄先补成 20，再转成 0；100 岁则转成约 11.314：

```python
print(np.round(train_z.ravel(), 3))  # [-1.414 0. 0. 1.414]
print(np.round(test_z.ravel(), 3))   # [0. 11.314]
```

顺序是“先补年龄，再按训练尺度换算”。100 岁变成很大的标准分数，提醒我们检查该输入是否合理；缩放不会自动删去它，也不会强制把它限制在某个区间。

注意：测试集变换后不要求均值也等于 0、方差也等于 1，因为使用的是训练集参数。若为了达到这两个数重新 `fit` 测试集，就改变了模型看到的坐标系。

**手算例题。** 训练集某特征均值为 50，标准差为 10。新样本值 65 对应 $z=(65-50)/10=1.5$。树中若有条件 `z <= -0.5`，还原为原单位即 $x\leq 50-0.5\times10=45$。

## 5. 类别编码：整数标签不等于数值大小

顺序编码（Ordinal Encoding）把类别映射成整数。如果类别本身有顺序，例如低、中、高，指定有意义的顺序通常合理。如果类别没有顺序，例如城市 A、B、C，编码成 0、1、2 可能引入不合理的大小关系或限制切分方式。

独热编码（One-Hot Encoding）为每个类别建立指示列。例如城市 B 表示为 `[0, 1, 0]`。通常不应把它理解成连续数量。

```python
city = pd.Series(["A", "B", "C", "A"], name="city")
print(pd.get_dummies(city, dtype=int))
```

| 原始类别 | A | B | C |
|---|---:|---:|---:|
| A | 1 | 0 | 0 |
| B | 0 | 1 | 0 |
| C | 0 | 0 | 1 |

类别很多时，独热编码会产生大量列。可以依据业务知识合并类别；不要仅为减少列数任意合并有明显业务差异的取值。课程提到降维，但不需要在本章自行扩展到主成分分析的推导。

独立对训练集和测试集调用 `get_dummies()`，可能得到不同的列集合。更稳妥的通用方式是拟合编码器后重用它：

```python
from sklearn.preprocessing import OneHotEncoder

encoder = OneHotEncoder(handle_unknown="ignore", sparse_output=False)
train_cat = np.array([["A"], ["B"], ["A"]])
test_cat = np.array([["B"], ["C"]])

encoder.fit(train_cat)
print(encoder.get_feature_names_out(["city"]))
print(encoder.transform(test_cat))
# B -> [0., 1.]；未知 C -> [0., 0.]
```

**为什么 B 变成 `[0,1]`，C 变成 `[0,0]`？** 训练时只出现 A、B，因此输出两列 `city_A`、`city_B`，而不是为未来每个可能的城市预留一列。新客户来自 B，就填“不是 A、是 B”；C 在训练中没见过，指定忽略未知类别后，两列都为 0。增加新样本不会自动增加第三列，否则已训练模型的输入列数就对不上了。

`handle_unknown="ignore"` 解决未知类别的转换报错问题，不会让模型自动学会未知类别的行为。上述“全零”是该原始特征对应的编码块，不是把整个样本变成零。

## 6. 预处理顺序与代码阅读

典型数值分支：缺失填充 → 标准化。典型类别分支：缺失填充 → 独热编码。两条分支合并后送入模型，见第 09 章的完整流水线（Pipeline）。

从字符串转换数值时，`pd.to_numeric(..., errors="coerce")` 会把无法解析的值变成缺失值，因此后续仍需检查与处理。`Pclass` 虽然存成整数，也可以按业务意义作为类别特征；数据类型与特征的统计含义不是一回事。

## 7. 纸笔自测

1. 训练收入为 `[10, 20, 30, NaN]`，测试收入为 `[100, NaN]`。均值填充时，测试缺失值应填多少？
2. 标准化能否消除偏态？标准化后的测试集均值必须为 0 吗？
3. $Q_1=20,Q_3=40$，常用箱线图异常上下界是多少？
4. 为什么应把填充器放进交叉验证的流水线，而不是先填完整份数据？
5. 对城市编码为 0、1、2，相比独热编码可能引入什么问题？

### 自测答案

1. 20，使用训练集非缺失值的均值。不能用测试集中的 100 来填。
2. 均不能保证。标准化是中心化与缩放，测试集使用训练参数。
3. $IQR=20$，下界 $20-30=-10$，上界 $40+30=70$。
4. 每个验证折的填充值只能由该折的训练数据学习，避免泄漏。
5. 人为赋予类别顺序或距离；类别本身没有这些关系时会误导某些模型。
