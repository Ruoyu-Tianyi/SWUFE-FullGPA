## 1. 容易误记的概念

| 主题 | 应掌握的准确表述 | 复习位置 |
| --- | --- | --- |
| 字典（Dictionary） | 现代 Python 的 `dict` 保持插入顺序；键仍用于查找，不等于列表的位置索引 | 02 |
| 集合（Set） | 普通 `set` 可变，元素唯一，无位置索引；不可变版本是 `frozenset` | 02 |
| 数组切片（Array slicing） | NumPy 基本切片共享数据；布尔/整数数组等高级索引通常产生副本。不要把所有索引都当视图 | 03 |
| 分组最大值（Group maximum） | 每列独立聚合，结果可能不对应任何一条原始记录 | 04 |
| 箱线图（Box plot） | 常用围栏为 Q1−1.5IQR、Q3+1.5IQR，不是中位数±1.5IQR；须线到围栏内最远实际观测 | 05 |
| 标准化（Standardization） | 减训练均值、除训练标准差，不会保证正态分布，也不是压到 [0,1] | 07 |
| 缺失填补（Imputation） | 默认 `SimpleImputer()` 用均值；字符串类别须显式指定合适策略，如 `most_frequent` | 07、09 |
| 测试集预处理（Test transformation） | 使用训练时学到的填补/缩放规则，不能各自重新 fit 后当作同一特征尺度 | 07、09 |
| 树的纯叶（Pure leaf） | 不限制深度也不保证训练准确率 100%；相同特征但冲突标签无法完全分开 | 08 |
| 交叉验证（Cross-validation） | 提供验证估计以选择方案；本身不会自动改变模型复杂度或消除过拟合 | 09 |
| 精确率与阈值（Precision and threshold） | 固定分数时提高阈值使预测正集合缩小，召回率不增加；精确率不保证逐点单调增加 | 09 |
| 特征重要性（Feature importance） | 依赖当前模型、数据和度量；不是因果效应，不纯度重要性本身也不给方向 | 09 |
| 正规方程（Normal equation） | 显式逆公式要求设计矩阵列满秩；实际数值实现可用稳定的最小二乘求解，不必直接求逆 | 10 |
| 决定系数（R-squared） | 可为负，不是“准确率”；其 SST 使用当前评价集真实 y 的均值 | 10 |
| 零梯度（Zero gradient） | 一般目标可能有极大值或鞍点；线性回归的平方误差是凸目标，零梯度点为全局最小点 | 11 |
| SGD 的默认目标 | `SGDRegressor` 默认带 L2；要与无正则普通最小二乘比较同一目标，应明确 `penalty=None` | 11 |
| 随机森林分类预测 | sklearn 聚合各树类别概率；不要把其实现一概写成“每树先硬分类，再多数投票” | 12 |
| 袋外数据（OOB） | 相对于每棵树定义；某行的 OOB 预测只聚合没有用该行训练的树 | 12 |

上述软件行为可核对：[Python 数据结构](https://docs.python.org/3/tutorial/datastructures.html)、[NumPy 索引](https://numpy.org/doc/stable/user/basics.indexing.html)、[NumPy 广播](https://numpy.org/doc/stable/user/basics.broadcasting.html)、[Matplotlib 箱线图](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.boxplot.html)、[StandardScaler](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html)、[SimpleImputer](https://scikit-learn.org/stable/modules/generated/sklearn.impute.SimpleImputer.html)。

评估与模型细节可核对：[交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)、[Pipeline](https://scikit-learn.org/stable/modules/generated/sklearn.pipeline.Pipeline.html)、[置换重要性](https://scikit-learn.org/stable/modules/permutation_importance.html)、[LinearRegression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LinearRegression.html)、[R²](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.r2_score.html)、[SGDRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.SGDRegressor.html)、[RandomForestClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)。

## 2. AdaBoost 的公式约定

课程讲义写出学习器权重 $\alpha=\eta\ln((1-\epsilon)/\epsilon)$，并在例子中取 $\eta=0.5$，配合正确/错误样本的对称指数更新。常见二分类教材使用 $\alpha=\tfrac12\ln((1-\epsilon)/\epsilon)$ 配同样的对称更新；这两者在该例子的取值下相符。

因此，**必须把系数与样本权重更新式成对阅读**。不要把一个版本的系数与另一个版本的更新方式混合，也不要认为任意学习率都会使更新后的错分样本权重和恰好为 0.5。第 12 章保留课程约定，并说明对应条件。

来源：[集成学习讲义](https://bana409.harrywang.me/docs/lectures/ensemble-learning)。这属于公式记号与实现约定的区分，不新增一套独立考试算法。

## 6. 常用术语速查

| 中文（英文） | 中文（英文） | 中文（英文） |
| --- | --- | --- |
| 样本（Instance） | 特征（Feature） | 目标/标签（Target/Label） |
| 监督学习（Supervised learning） | 分类（Classification） | 回归（Regression） |
| 泛化（Generalization） | 过拟合（Overfitting） | 欠拟合（Underfitting） |
| 广播（Broadcasting） | 布尔掩码（Boolean mask） | 分组聚合（Group aggregation） |
| 缺失填补（Imputation） | 标准化（Standardization） | 独热编码（One-hot encoding） |
| 不纯度（Impurity） | 熵（Entropy） | 信息增益（Information gain） |
| 准确率（Accuracy） | 精确率/查准率（Precision） | 召回率/查全率（Recall） |
| 交叉验证（Cross-validation） | 超参数（Hyperparameter） | 数据泄漏（Data leakage） |
| 流水线（Pipeline） | 置换重要性（Permutation importance） | 不纯度重要性（Impurity importance） |
| 损失函数（Loss function） | 梯度（Gradient） | 学习率（Learning rate） |
| 偏差（Bias） | 方差（Variance） | 噪声（Noise） |
| 投票（Voting） | 装袋法（Bagging） | 提升法（Boosting） |
| 自助抽样（Bootstrap sampling） | 袋外评估（Out-of-bag evaluation） | 随机森林（Random forest） |

注意：线性模型的偏置项（Bias term/Intercept）与偏差—方差中的偏差（Bias）不是同一个概念；同一个英文单词要按上下文理解。
