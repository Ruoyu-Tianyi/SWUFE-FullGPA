## 4. 范围边界

官方明确排除的独立章节：多项式回归与正则化（Polynomial Regression and Regularization）、逻辑回归（Logistic Regression）、支持向量机（Support Vector Machine）、聚类（Clustering）、代码管理（Code Management）、数据应用（Data App）。不需要为这些章节准备单独的公式与 API 清单。

同一术语若出现在范围内章节，仍需理解其当时的用途。例如：概览中的无监督学习、树的复杂度约束、投票中使用不同模型，不能因为另一个独立章节被排除而全部跳过。

课程的 ROC/AUC、正规方程推导、OLS 与 R²等页面带有 optional 标记。**optional 不等于考试页明确排除**；先掌握正文，再学习这些标注拓展的细节。R²在作业 4 明确使用，本资料将基本公式与解释列为主线。作业 4 的 Data App 部分依然属于官方排除章节。

## 5. 三轮复习法

### 第一轮：理解结构

按 01→12 阅读。每章结束后，不看笔记回答：“输入是什么？输出是什么？核心规则是什么？什么条件下会失效？”此时只标记不熟的知识，不急着把整章抄到 A4 上。

### 第二轮：纸笔练习

做章末自测及综合题。公式题写符号含义、代入式和结果；代码题写对象类型、shape 或输出；判断题即使答对，也要能解释为什么。遇到错误时回到对应章节，而不是仅背正确选项。

### 第三轮：压缩与模拟

将经常混淆的公式、条件和短代码压缩到手写提纲。做一次 75 分钟限时练习，记录查表耗时，删去熟悉而占位置的内容，补入真实错点。
