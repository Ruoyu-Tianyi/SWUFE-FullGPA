## 1. 为什么组合模型

集成把多个基学习器（Base learner）的预测组合起来。有效的条件是：成员具有预测能力，而且错误不完全相同；数量多本身不保证优于最佳单模型。

对平方误差，在适当统计假定下，期望预测误差可分解为：

$$
\mathbb E[\text{squared prediction error}]
=\text{Bias}^2+\text{Variance}+\text{Irreducible noise}
$$

| 概念 | 中文含义 | 常见表现 |
|---|---|---|
| 偏差（Bias） | 模型的系统性近似误差 | 用直线拟合明显弯曲关系，训练和验证都不好 |
| 方差（Variance） | 换一批训练样本，模型变化有多大 | 深树对样本敏感，训练好而验证差 |
| 不可约噪声（Irreducible noise） | 给定现有特征仍无法确定的随机变化 | 无法仅靠更复杂模型消除 |

课程用噪声举例时也提到录入或测量错误；这些可通过数据清理减少，但不能据此说所有随机噪声都能清理掉。

浅树通常偏差较高、方差较低；深树通常偏差较低、方差较高。装袋主要降低方差，提升常通过逐步修正来降低偏差；这描述典型作用，不是所有数据和参数下的绝对定律。

## 2. 三类方法总览

| 方法 | 成员与数据 | 训练关系 | 预测组合 | 主要直觉 |
|---|---|---|---|---|
| 投票（Voting） | 常用不同类型模型，使用相同训练集 | 可独立训练 | 多数票／概率平均／回归平均 | 利用不同模型的互补性 |
| 装袋（Bagging） | 常用同类模型，各用不同自助样本 | 可并行 | 平均或投票 | 降低对单一训练样本的敏感性 |
| 提升（Boosting） | 通常逐步加入弱学习器 | 前后依赖、顺序训练 | 加权组合或逐步相加 | 新成员修正现有集成的不足 |

随机森林（Random Forest）属于装袋思路；AdaBoost、梯度提升（Gradient Boosting）和 XGBoost 属于提升。

## 3. 硬投票与软投票

硬投票（Hard voting）数类别票数；软投票（Soft voting）先平均各模型的类别概率，再选平均概率最大的类别。加权投票还可给不同模型不同权重。

**课程型手算题**：三个模型给出类别 A 的概率为 $0.90,0.45,0.45$，B 的概率为其补数。

- 三个硬预测为 A、B、B，硬投票选择 B。
- A 的平均概率为 $(0.90+0.45+0.45)/3=0.60$，软投票选择 A。
- 软投票保留了模型“有多确信”的信息；概率估计不可靠时，并不保证优于硬投票。

软投票要求所有成员能够提供类别概率。课程对 `SVC` 使用概率校准（Probability calibration）；只提供 `decision_function` 得分还不等于直接具备 `predict_proba`。

下面代码可独立运行；它展示课程中的三类成员，不要求复习 Logistic Regression 或 SVM 的数学推导。

```python
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.calibration import CalibratedClassifierCV
from sklearn.ensemble import VotingClassifier
from sklearn.metrics import accuracy_score

X, y = make_moons(n_samples=300, noise=0.25, random_state=409)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=409
)
vote = VotingClassifier(
    estimators=[
        ("tree", DecisionTreeClassifier(max_depth=3, random_state=409)),
        ("lr", LogisticRegression()),
        ("svm", CalibratedClassifierCV(
            SVC(), cv=3, ensemble=False  # 得分转为概率
        )),
    ],
    voting="soft",
)
vote.fit(X_train, y_train)
print(accuracy_score(y_test, vote.predict(X_test)))
```

回归任务可平均成员的数值预测；例如三模型预测 $100,120,140$，等权平均结果为 $120$。

## 4. 装袋、自助采样与 OOB

自助采样（Bootstrap sampling）从原来 $n$ 行中**有放回**抽取；典型 bagging 每个样本包抽 $n$ 次，所以包的行数仍为 $n$，但会有重复行，也有未出现的原始行。

粘贴法（Pasting）采用无放回采样，不能与 bootstrap 混淆。

某一固定原始样本，在一次抽取中未被选中的概率为 $1-1/n$，独立抽 $n$ 次都未选中的概率为：

$$
P(\text{OOB})=\left(1-\frac1n\right)^n\longrightarrow e^{-1}\approx0.368
$$

因此大样本下，每个包约含原始数据中 63.2% 的不同样本，约 36.8% 为袋外样本（Out-of-bag, OOB）。这两个百分数是期望近似，不是每一包都恰好如此；若抽取次数不同，公式也应改变。

**手算题**：原始数据仅有 5 行，每包抽 5 次。某行成为 OOB 的概率是 $(4/5)^5=0.32768$，不是精确的 0.368；包内不同原始行的期望数量为 $5(1-0.32768)=3.3616$。

OOB 评估的正确思路：

1. 固定一个训练样本 $i$。
2. 只找训练时没有抽到 $i$ 的那些树。
3. 用这些树的预测组合出样本 $i$ 的 OOB 预测。
4. 对有可用 OOB 预测的训练样本汇总评分。

所以 OOB 分数不是森林直接在全部训练样本上的普通训练分数，也不是“每棵树自己的 OOB 准确率简单平均”。树太少时，有的样本可能没有足够 OOB 预测。

OOB 可作为训练数据内部的泛化估计；它并不保证与独立测试得分完全相同，也不授权反复看最终测试集调参。

## 5. 随机森林

随机森林让树之间产生差异的两个主要来源：

- **样本随机性**：每棵树使用不同 bootstrap 样本。
- **特征随机性**：每个节点分裂时，只从随机抽取的一部分候选特征中找分裂。

不是“每棵树开始时只抽一次特征，并在整棵树中固定使用”。减少树之间的相关性，使平均后的预测通常更稳定。

| 参数／属性 | 读法 |
|---|---|
| `n_estimators` | 森林中的树数，区别于每棵树深度 |
| `max_features` | 每次分裂考虑的候选特征数 |
| `max_depth` | 单棵树深度上限 |
| `min_samples_leaf` | 叶节点最少样本数 |
| `bootstrap` | 是否采用有放回样本包 |
| `oob_score=True` | 请求 OOB 评估，要求 `bootstrap=True` |
| `oob_score_` | 拟合后得到的 OOB 分数 |

`max_depth=None` 表示没有显式深度上限，不代表任何数据都能得到纯叶；特征完全相同而标签冲突等情况仍会阻止进一步区分。

分类森林中，sklearn 先平均各树的类别概率，再选择概率最大的类别；不要将其实现绝对化为“每棵树给一张等权硬票”。回归森林平均各树的数值预测。[RandomForestClassifier 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)

以下代码沿用第 3 节投票例子的数据拆分；只用训练数据拟合。

```python
from sklearn.ensemble import RandomForestClassifier

forest = RandomForestClassifier(
    n_estimators=150, max_features="sqrt",
    bootstrap=True, oob_score=True, random_state=409
)
forest.fit(X_train, y_train)
print(forest.oob_score_)          # 训练数据内部评估
print(accuracy_score(y_test, forest.predict(X_test)))
```

作业 4 用 `RandomForestRegressor` 预测手机价格，搜索 2 个树数和 2 个深度，共 4 组参数，5 折为 20 次折内训练，默认再重拟合 1 次。

树可以刻画非线性与交互作用（Interaction）：同样的“裂屏”对旗舰机和低价机的预测影响可以不同；只有加性原始特征的线性模型则给出固定差额。森林是否更好仍须由验证数据判断。

## 6. AdaBoost：两类权重

自适应提升（Adaptive Boosting, AdaBoost）顺序训练弱学习器，重点关注之前容易错的样本。先区分：

- 样本权重 $w_i^{(t)}$：训练第 $t$ 个学习器时，第 $i$ 行算多重要。
- 学习器权重 $\alpha_t$：最终预测时，第 $t$ 个学习器的意见算多重要。

课程采用标签 $y_i\in\{-1,+1\}$，初始化每行权重为 $1/n$。第 $t$ 轮：

$$
\epsilon_t=\frac{\sum_iw_i^{(t)}\,\mathbf1[h_t(x_i)\ne y_i]}{\sum_iw_i^{(t)}}
$$

按课程页面的系数约定：

$$
\alpha_t=\eta\ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right),\qquad
\widetilde w_i=w_i^{(t)}e^{-\alpha_ty_ih_t(x_i)},\qquad
w_i^{(t+1)}=\frac{\widetilde w_i}{\sum_j\widetilde w_j}
$$

这里的对数是自然对数 $\ln$，不同于熵公式常用的 $\log_2$。

当 $0<\epsilon_t<0.5$ 且 $\eta>0$ 时，$\alpha_t>0$。预测错误时 $y_ih_t(x_i)=-1$，未归一化权重乘 $e^{+\alpha_t}$；正确时乘 $e^{-\alpha_t}$。最后必须归一化。

最终分类：

$$
H(x)=\operatorname{sign}\left(\sum_t\alpha_th_t(x)\right)
$$

### 公式约定：考试按题目给定的一整套公式

课程写 $\alpha=\eta\ln((1-\epsilon)/\epsilon)$，并在餐厅例题中取 **$\eta=0.5$**。常见二分类教材的基本版本在同样的对称权重更新式下写 $\alpha=\frac12\ln((1-\epsilon)/\epsilon)$；若另外引入收缩率 $\nu$，可写为 $\frac\nu2\ln((1-\epsilon)/\epsilon)$。课程例题等价于教材基本版本；不要把两者的学习率符号数值直接一一对应，也不要把某版本的系数与另一版本的更新式拼在一起。[二分类 AdaBoost 推导](https://www.cs.cornell.edu/courses/cs3780/2026sp/lectures/lecturenote19.html)

此外，sklearn 的算法实现与多分类推广另有配套约定，不能只比较 `learning_rate` 数值就断言其每一步必定复现手算表。

### 手算一轮：10 行，错 3 行

初始每行权重 $0.1$，加权错误率 $\epsilon=0.3$，按课程取 $\eta=0.5$：

$$
\alpha=0.5\ln(0.7/0.3)\approx0.42365
$$

| 样本 | 未归一化新权重 | 归一化后每行权重 |
|---|---:|---:|
| 3 条错分行 | $0.1e^{\alpha}\approx0.15275$ | $1/6\approx0.16667$ |
| 7 条正确行 | $0.1e^{-\alpha}\approx0.06547$ | $1/14\approx0.07143$ |

总和 $Z\approx0.91652$。错分行新权重总和为 $3/6=0.5$，正确行总和也为 $7/14=0.5$。

“错分行新总权重恰好为一半”在这里由特定系数产生；按课程公式换成任意 $\eta$ 时不必成立。一般新错分权重占比为 $\frac{\epsilon e^{\alpha}}{\epsilon e^{\alpha}+(1-\epsilon)e^{-\alpha}}$。

```python
import numpy as np

weights = np.full(10, 0.1)
wrong = np.array([True] * 3 + [False] * 7)
error = weights[wrong].sum() / weights.sum()
alpha = 0.5 * np.log((1 - error) / error)  # 课程例题约定
weights *= np.where(wrong, np.exp(alpha), np.exp(-alpha))
weights /= weights.sum()                  # 归一化
print(alpha, weights[0], weights[-1])
print(weights[wrong].sum(), weights.sum()) # 0.5、1.0
```

后续轮次计算的是**加权**错误率：错同样 3 行，若其权重不同，错误率可以不同。课程餐厅例题的三学习器约重 $0.42,0.65,0.75$；对一个投票为 $+1,+1,-1$ 的样本，最终分数约为 $0.32>0$，预测 $+1$。

## 7. 梯度提升与 XGBoost

AdaBoost 调整样本权重；梯度提升逐步添加预测函数来改善当前集成。平方损失回归中，可用当前残差训练下一棵树：

$$
r_i^{(t)}=y_i-F_{t-1}(x_i),\qquad
F_t(x)=F_{t-1}(x)+\eta h_t(x)
$$

其中 $h_t$ 拟合本轮残差。更一般的损失使用负梯度形成的伪残差（Pseudo-residual），所以不能把所有分类梯度提升都简单写成“用 0/1 标签减最终类别”。

**手算小例**：真实值 $y=10$，当前预测 $F_0=6$，新树给出残差预测 $h_1=3$，学习率 $0.1$，则新预测为 $6+0.1(3)=6.3$，不是 $9$，也不是直接改为 $3$。

XGBoost 是高效实现梯度提升的一套工具。会辨认 `XGBClassifier`／`XGBRegressor` 的任务类型即可；本章无需展开其系统优化细节。

梯度下降（GD）更新给定模型的参数；梯度提升（GB）逐步加入新学习器，两者名称相近，但不是同一算法。提升模型中学习率、树数和树复杂度需要共同调节；更多轮数不保证测试性能更好。

## 8. 易错点与纸笔自测

易错点：把 bagging 写成无放回；认为每个包只含 63.2% 行；把每节点抽特征写成每树只抽一次；用参与训练该行的树计算其 OOB 预测；忽略 AdaBoost 归一化；把所有“错三条”都当 30%；认为集成必胜或不会过拟合。

**自测**：

1. 三个 A 类概率为 $0.51,0.51,0.01$，硬投票与软投票分别选什么？
2. 某样本被第 1、3 棵树的 bootstrap 样本抽到，未被第 2、4 棵抽到；它的 OOB 预测用哪些树？
3. AdaBoost 中，两行权重各为 0.4，其余八行各 0.025；若只错这两行，错误率是多少？
4. 固定其他条件，`n_estimators=200` 是否表示每棵树深度 200？
5. 回归梯度提升当前预测 8，新树预测残差 −2，学习率 0.2，新预测多少？

**答案**：1. 硬投票 A；软投票 A 均值约 0.343，因此 B。2. 第 2、4 棵。3. 0.8，尽管仅错 20% 的行。4. 否，表示 200 棵树。5. $8+0.2(-2)=7.6$。
