# 08 决策树（Decision Tree）

[返回复习导航](00_复习导航.md)

本章复习顺序：沿树预测 → 计算纯度与信息增益 → 选择切分 → 限制复杂度 → 读懂训练代码。掌握小型手算比记住完整树图更重要。

## 1. 一棵树如何做预测

根节点（Root Node）提出第一个问题；内部节点（Internal Node）继续检查特征；叶节点（Leaf Node）给出最终结果。一个样本从根出发，沿条件分支走到一个叶节点。

分类树（Classification Tree）输出类别，常用叶内多数类作为预测；`predict_proba()` 根据叶内类别比例返回概率，在使用样本权重时是加权比例。

回归树（Regression Tree）输出数值；在平方误差准则下，叶节点预测该叶内训练目标的均值。

分类与回归树（Classification and Regression Trees, CART）可处理两类任务。课堂的 ID3 例子可按类别作多分支切分，而 scikit-learn 的 CART 实现使用二叉切分，不要把所有树都想成同一种分支结构。

```text
Fare <= 30 ?
├─ True：预测 0
└─ False：Age <= 10 ?
           ├─ True：预测 1
           └─ False：预测 0
```

例如 `Fare=50, Age=8` 最终预测 1；`Fare=20, Age=8` 在第一层就到达叶节点，不再检查年龄。上图为自建示意，不是课堂数据训练结果。

## 2. 不纯度、熵与基尼不纯度

纯度（Purity）描述节点中的类别是否一致。只有一个类别的节点是纯节点；类别分布越均匀，通常越不纯。

设节点中共有 $K$ 个类别，第 $k$ 类占比为 $p_k$。

熵（Entropy）：

$$H=-\sum_{k=1}^{K}p_k\log_2 p_k.$$

约定 $0\log_2 0=0$。二分类纯节点的熵为 0；两类各一半时熵为 1。多分类熵的最大值是 $\log_2 K$，所以“熵最大为 1”只适用于这里的二分类情况。

基尼不纯度（Gini Impurity）：

$$G=1-\sum_{k=1}^{K}p_k^2.$$

二分类纯节点的 Gini 为 0；各一半时为 0.5。不要把 Gini 与准确率混为一谈。

| 二分类比例 | 熵 | Gini | 解释 |
|---|---:|---:|---|
| 1 与 0 | 0 | 0 | 完全纯 |
| 0.5 与 0.5 | 1 | 0.5 | 最不纯 |
| 0.8 与 0.2 | 约 0.722 | 0.32 | 比各半更纯 |

scikit-learn 的 `DecisionTreeClassifier` 默认准则为 `gini`；课堂手算重点是 `entropy`。API 的另一个取值写作 `"log_loss"`，中间有下划线。

## 3. 信息增益必须按子节点大小加权

父节点有 $n$ 个样本，切分为多个子节点，第 $j$ 个子节点有 $n_j$ 个样本，其熵为 $H_j$。信息增益（Information Gain）为：

$$IG=H_{parent}-\sum_j\frac{n_j}{n}H_j.$$

比较同一父节点的候选切分，选择信息增益最大的切分，也就是切分后加权熵最小的切分。子节点数量不相同时，不能简单对其熵取算术平均。

如果采用 Gini，则把公式里的熵换成 Gini，得到对应的不纯度下降（Impurity Decrease）。

### 手算例题：选择哪种切分

以下是自建频数表。父节点有 10 个样本，正类 6 个、负类 4 个。

| 候选切分 | 左子节点：正/负 | 右子节点：正/负 |
|---|---:|---:|
| A | 4 / 0 | 2 / 4 |
| B | 3 / 2 | 3 / 2 |

父节点熵：

$$H_{parent}=-0.6\log_2 0.6-0.4\log_2 0.4\approx0.971.$$

A 的左子节点纯，熵为 0；右子节点熵为：

$$H_R=-\frac13\log_2\frac13-\frac23\log_2\frac23\approx0.918.$$

于是：

$$IG_A=0.971-\left(\frac4{10}\times0+\frac6{10}\times0.918\right)\approx0.420.$$

B 的两个子节点比例都与父节点相同，故加权熵仍为 0.971，$IG_B=0$。应选择 A。

若改用 Gini，父节点为 $1-0.6^2-0.4^2=0.48$，A 的加权子节点 Gini 为 $(6/10)\times(4/9)\approx0.267$，下降约 0.213。这里两种准则都选择 A，但一般不保证所有候选切分的排序相同。

## 4. 对应课堂 Golf 数据的关键结果

课堂 Golf 数据有 9 个 `yes`、5 个 `no`，父节点熵约 0.940。按 `Outlook` 分组后的频数为：

| Outlook | yes | no | 总数 |
|---|---:|---:|---:|
| sunny | 3 | 2 | 5 |
| overcast | 4 | 0 | 4 |
| rainy | 2 | 3 | 5 |

按原始比例计算，加权熵为 $\frac5{14}H(3/5,2/5)+\frac4{14}\times0+\frac5{14}H(2/5,3/5)\approx0.693536$，保留三位小数为 0.694，信息增益约 0.247。课件显示的 0.693 是近似展示，手算以原始比例计算为准。

`Outlook` 在该例中优于 `Humidity`、`Windy`、`Temp`，所以成为根节点。后续只在相应子集内重新计算：

- `overcast` 全为 `yes`，直接成为叶节点。
- `sunny` 按 `Windy` 切分后变纯。
- `rainy` 按 `Humidity` 切分后变纯。

不同教材的经典 Golf 表可能交换 `sunny` 与 `rainy` 的命名；做本课题目应使用本课给定频数，不要套用背熟的另一张表。

## 5. 数值特征的切分点

对排序后的不同取值，可以考虑相邻不同值的中点。例如 `[10, 20, 20, 40]` 的候选中点为 15 和 30，而不是在重复的 20 之间制造有效分组。

每个候选阈值都形成“$x\leq t$”与“$x>t$”两个子集，再计算不纯度下降。也可先分箱（Binning），把数值转成区间类别，但可能损失细节。

贪心算法（Greedy Algorithm）在当前节点选择最佳切分，不保证得到所有可能树中全局最优的一棵树。

## 6. 为什么要剪枝

不断切分通常能降低训练误差，却可能记住偶然差异，导致过拟合（Overfitting）。限制树的复杂度属于正则化（Regularization）；虽然后续“多项式回归与正则化”章节被排除，树的剪枝仍在本章范围内。

预剪枝（Pre-pruning）在生长时限制树：

| 参数 | 含义 | 通常使树更简单的方向 |
|---|---|---|
| `max_depth` | 根到叶最多经过多少层分裂 | 减小 |
| `min_samples_split` | 节点至少包含多少样本才可尝试切分 | 增大 |
| `min_samples_leaf` | 任一叶节点至少有多少样本 | 增大 |
| `max_leaf_nodes` | 最多允许多少叶节点 | 减小 |
| `min_impurity_decrease` | 允许切分所需的最低加权不纯度下降 | 增大 |

在二叉树中，根深度记为 0，`max_depth=3` 至多产生 $2^3=8$ 个叶节点；实际可能更少。浅树也可能含只覆盖一个样本的叶节点，因此深度限制与最小叶样本量不是同一约束。

`min_impurity_decrease` 的库实现还考虑当前节点占全部训练样本的权重；不要无条件把它等同于未加权的局部 $IG$。

默认不限制深度的树**不保证**所有叶节点都纯。例如两行特征完全相同但标签相反，就无法再通过特征将它们分开。默认树训练准确率可能达到 1，但不能据此保证测试表现。

### 后剪枝 `ccp_alpha`：课程标为可选（Optional）

代价复杂度剪枝（Cost-Complexity Pruning）权衡拟合误差与叶节点数量：

$$R_\alpha(T)=R(T)+\alpha|L(T)|,$$

其中 $R(T)$ 是叶节点按样本占比加权的不纯度，$|L(T)|$ 为叶节点数。更大的 `ccp_alpha` 使额外叶节点更“昂贵”，通常得到更小的树。具体最优值要由验证或交叉验证选择。

本小节在课件中标为可选；考试页没有单独明确排除，建议至少掌握方向和含义。

## 7. 最小训练代码与输出解释

以下代码使用自建数据，目的是读懂 `fit`、`predict` 和叶节点概率。

```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

X = pd.DataFrame({"fare": [5, 10, 20, 50, 60, 70]})
y = [0, 0, 0, 1, 1, 1]

model = DecisionTreeClassifier(
    criterion="entropy", max_depth=1, random_state=42
)
model.fit(X, y)

new = pd.DataFrame({"fare": [15, 55]})
print(model.predict(new))        # [0, 1]
print(model.classes_)            # [0, 1]
print(model.predict_proba(new))  # [[1., 0.], [0., 1.]]
print(model.get_depth())         # 1
print(model.get_n_leaves())      # 2
```

`fit(X, y)` 学习切分；`predict(new)` 使用已经学好的规则，不会重新训练。预测输入必须与训练时的特征定义和顺序一致。类别变量的编码与缺失值处理应纳入第 09 章的流水线。

叶中 100% 为某类，是当前训练数据支持的叶内比例，不表示未来预测具有绝对确定性。

## 8. 读树图的细节

- scikit-learn 图中 `feature <= threshold` 条件成立走左分支，不成立走右分支。
- `Sex_female <= 0.5` 表示该独热列为 0，即不是已编码的 `female` 类。只有数据确实只有男/女两类时，才能直接称为男性。
- 若数值特征先标准化，阈值也是标准化单位，需要按 $x=\mu+z\sigma$ 还原。
- `samples` 表示到达节点的训练样本数量或比例，取决于作图选项；`value` 的显示也受版本、权重和作图参数影响，应先读图例。
- `class` 是节点的预测类别；`entropy` 或 `gini` 是不纯度，不是预测错误率。

## 9. 纸笔自测

1. 二分类节点有 5 个正类和 5 个负类，熵和 Gini 分别为多少？
2. 两个子节点熵分别为 0 和 1，样本数分别为 90 和 10。加权熵是多少？
3. `min_samples_split=10` 能否保证每个叶节点至少有 10 个样本？
4. 为什么训练准确率为 1 不能说明模型已经足够好？
5. 一个叶节点有 3 个负类、7 个正类，在无权重设置下预测类别和正类概率是什么？

### 自测答案

1. 熵为 1，Gini 为 0.5。
2. $(90/100)\times0+(10/100)\times1=0.1$，不是 0.5。
3. 不能。它限制父节点能否尝试切分；最小叶节点样本量由 `min_samples_leaf` 控制。
4. 可能记住训练集噪声，需用未参与拟合与选择的独立数据检验泛化。
5. 预测正类 1，正类概率为 0.7。
