## 第一课时：DTMC 基本定义与 n 步转移概率

### 1.1 随机过程基本定义

- **随机过程（Random Process）**：一族随机变量的集合 $\{X_t, t \in T\}$，其中指标集 $T$ 可以是时间（离散或连续）。
- **状态空间**：所有可能的取值构成的集合。
- **样本轨道**：固定一个样本点 $\omega$，函数 $t \mapsto X_t(\omega)$ 称为一个样本轨道或一个实现。
- **离散时间 vs 连续时间**：当指标集 $T$ 为离散整数集时，为离散时间随机过程；当 $T$ 为连续区间时，为连续时间随机过程。

### 1.2 马尔可夫链（Markov Chain）的定义

- **马尔可夫性（Markov Property）**：
  $$P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \ldots, X_0 = i_0) = P(X_{n+1} = j \mid X_n = i)$$
  即：**已知现在，未来与过去无关**。
- **齐次马尔可夫链**：一步转移概率与时刻无关：$P(X_{n+1}=j \mid X_n=i) = P_{ij}$。
- **DTMC（Discrete Time Markov Chain）**：离散时间齐次马尔可夫链，简称马尔可夫链。

### 1.3 转移概率与转移矩阵

- **一步转移概率矩阵**：$P = (P_{ij})$，其中 $P_{ij} = P(X_{n+1}=j \mid X_n=i)$。
- **转移矩阵性质**：每行元素和为 1，即 $\sum_{j} P_{ij} = 1$，且 $P_{ij} \geq 0$。
- **状态空间**：$S = \{0, 1, 2, \ldots\}$ 或有限集。

### 1.4 初始分布与状态分布

- **初始分布**：$P(X_0 = i) = a_i$，$\sum a_i = 1$。
- **状态分布的演化**：$P(X_n = j) = \sum_i a_i \cdot P_{ij}^{(n)}$，其中 $P^{(n)}$ 为 n 步转移矩阵。
- **矩阵表示**：$P^{(n)} = P^n$，$P(X_n = j) = (a P^n)_j$。

### 1.5 Chapman-Kolmogorov 方程（C-K 方程）

- **公式**：$P_{ij}^{(n+m)} = \sum_{k} P_{ik}^{(n)} P_{kj}^{(m)}$
- **矩阵形式**：$P^{(n+m)} = P^{(n)} P^{(m)}$
- **关键结论**：$P^{(n)} = P^n$（n 步转移矩阵 = 一步转移矩阵的 n 次幂）

## 第二课时：首步/首中时分解、常返/非常返、遍历、极限分布

### 2.1 首次到达时间

- **定义**：$f_{ij}^{(n)} = P(X_n = j, X_{n-1} \neq j, \ldots, X_1 \neq j \mid X_0 = i)$，表示从状态 $i$ 出发，**首次**在时刻 $n$ 到达状态 $j$ 的概率。
- **首步概率**：$f_{ij} = \sum_{n=1}^{\infty} f_{ij}^{(n)}$，从 $i$ 出发**最终到达** $j$ 的概率。
- **首步分解**：$P_{ij}^{(n)} = \sum_{k=1}^{n} f_{ij}^{(k)} P_{jj}^{(n-k)}$

### 2.2 状态分类：常返 vs 非常返

- **常返（Recurrent）状态**：$f_{ii} = 1$，即从状态 $i$ 出发一定会返回 $i$。
  - 等价条件：$\sum_{n=1}^{\infty} P_{ii}^{(n)} = +\infty$（返回次数期望为无穷）
  - **正常返（Positive Recurrent）**：$\mu_{ii} = E[T_{ii} \mid X_0=i] < +\infty$，平均返回时间有限。
  - **零常返（Null Recurrent）**：$\mu_{ii} = +\infty$，一定会返回，但平均返回时间无穷。
- **非常返（Transient）状态**：$f_{ii} < 1$，有正概率永远不再返回。
  - 等价条件：$\sum_{n=1}^{\infty} P_{ii}^{(n)} < +\infty$（返回次数期望有限）

### 2.3 状态的互通与类

- **可达**：$i \to j$（存在 $n$ 使 $P_{ij}^{(n)} > 0$）。
- **互通**：$i \leftrightarrow j$（$i \to j$ 且 $j \to i$）。
- **互通类**：互通关系是等价关系，划分状态空间为等价类（互通类）。
- **闭集**：互通类 $C$ 是闭集 $\iff$ 不存在从 $C$ 中状态到 $C$ 外状态的转移概率。
- **闭集判定**：$\sum_{j \in C} P_{ij} = 1$ 对所有 $i \in C$ 成立。
- **不可约（Irreducible）**：只有一个互通类，即所有状态互通。
- **性质**：同一互通类中所有状态具有相同的常返/非常返性质。

### 2.4 周期

- **周期定义**：$d(i) = \gcd\{n: P_{ii}^{(n)} > 0\}$，即所有返回时间的最大公约数。
- **非周期（Aperiodic）**：$d(i) = 1$。
- **周期状态**：$d(i) > 1$。
- **周期性质**：互通类中所有状态具有相同的周期。

### 2.5 遍历链（Ergodic Chain）

- **定义**：不可约、非周期、正常返的马尔可夫链。
- **遍历定理**：对于遍历链，存在唯一的**极限分布** $\pi = (\pi_0, \pi_1, \ldots)$，满足：
  $$\lim_{n \to \infty} P_{ij}^{(n)} = \pi_j, \quad \forall i, j$$

### 2.6 极限分布与稳态分布

- **极限分布**：$\pi_j = \lim_{n \to \infty} P_{ij}^{(n)}$，若存在且与 $i$ 无关。
- **极限分布的性质**：$\pi P = \pi$，$\sum_j \pi_j = 1$（归一化）。
- **与初态无关**：$\lim_{n \to \infty} P(X_n = j) = \pi_j$（对任意初始分布）。
- **极限分布求解**：解线性方程组 $\pi = \pi P$（流平衡方程），加归一化约束 $\sum \pi_j = 1$。

## 第三课时：流平衡、更新报酬定理、稳态分布

### 3.1 流平衡（Flow Balance）

- **基本思想**：对于状态 $j$，流入 $j$ 的"概率流"等于流出 $j$ 的"概率流"。
- **流平衡方程**：$\sum_i \pi_i P_{ij} = \pi_j$，即 $\pi P = \pi$。
- **与 C-K 方程的关系**：在稳态下，分布不再变化，故 $\pi P = \pi$。
- **求解稳态分布**：
  1. 写流平衡方程：对每个 $j$，$\sum_i \pi_i P_{ij} = \pi_j$
  2. 加归一化：$\sum_j \pi_j = 1$
  3. 解线性方程组（注意：流平衡方程中有一个是冗余的，可用归一化替换）。

### 3.2 状态空间分解定理

- **定理内容**：
  1. 所有常返状态构成闭集。
  2. 非常返状态可以分解为若干互通类，且每个非常返互通类都不是闭集。
  3. 状态空间分解为：常返闭集 + 若干非常返互通类。
- **不可约闭集**：常返状态构成的互通类是闭集，不可约。
- **有限状态空间**：有限状态空间马尔可夫链中，必存在常返状态（不存在全部非常返的情况）。

### 3.3 不可约 DTMC 的极限分布

- **定理（不可约、非周期、正常返）**：
  - 若 DTMC 不可约、非周期、正常返，则极限分布 $\pi$ 存在且唯一。
  - 反之，若极限分布存在，则链不可约、非周期、正常返。
- **定理（有限状态）**：有限状态不可约 DTMC 必为正常返，且存在唯一的稳态分布。

### 3.4 更新报酬定理（Renewal Reward Theorem）在 DTMC 中的应用

- **更新报酬定理**：在长期运行中，**单位时间的平均报酬** = **一个更新周期内的期望报酬** / **期望更新周期长度**。
- **DTMC 中的更新周期**：两次访问某个常返状态之间的时间间隔。
- **应用**：计算 DTMC 的稳态分布、长期平均成本/收益等。
- **典型应用**：在稳态下，状态 $j$ 被访问的时间比例等于 $\pi_j$。
- **与稳态分布的关系**：$\pi_j = \frac{1}{\mu_{jj}}$，其中 $\mu_{jj}$ 为从 $j$ 出发返回 $j$ 的期望时间。

### 3.5 生日与更新报酬定理的结合

- **长期频率**：在不可约正常返 DTMC 的稳态中，访问状态 $j$ 的**长期频率** = $\pi_j$。
- **带报酬的更新**：若每次进入状态 $j$ 获得报酬 $R_j$，则长期平均报酬 = $\sum_j \pi_j R_j$。
- **期望更新周期内的报酬**：$E[R] = \sum_j \pi_j R_j \cdot \mu_{ii}$（对某个参考状态 $i$）。

### 3.6 典型考点：稳态分布求解

- **求解步骤**：
  1. 写转移矩阵 $P$。
  2. 写流平衡方程 $\pi P = \pi$（注意去掉一个冗余方程）。
  3. 加归一化 $\sum \pi_j = 1$。
  4. 解线性方程组（可用高斯消元、矩阵求逆等）。
- **验证**：检查 $\pi_j > 0$ 且 $\sum \pi_j = 1$。

## 典型例题汇总

### 例题 1：判断状态常返/非常返

- **方法**：计算 $f_{ii}$ 或判断 $\sum_{n} P_{ii}^{(n)}$ 是否收敛。
- **有限状态**：有限状态不可约链必正常返。
- **无限状态**：可能正常返、零常返或非常返，需具体分析。

### 例题 2：求极限分布

- **条件**：确认链不可约、非周期、正常返（遍历）。
- **求解**：解 $\pi P = \pi$，$\sum \pi_j = 1$。
- **有限状态不可约链**：极限分布 = 稳态分布，一定存在。

### 例题 3：更新报酬定理应用

- **场景**：计算长期平均成本、收益、访问频率等。
- **公式**：$\text{长期平均报酬} = \frac{E[\text{一个周期内报酬}]}{E[\text{周期长度}]}$。
- **与稳态分布关系**：$\pi_j = \frac{1}{\mu_{jj}}$，长期平均报酬 = $\sum_j \pi_j R_j$。

### 例题 4：状态空间分解

- **步骤**：
  1. 画出状态转移图。
  2. 找出互通类。
  3. 判断每个互通类是否闭集。
  4. 常返类 = 闭集；非常返类 = 非闭集。
- **有限状态**：必有常返状态，分解为常返闭集 + 非常返类。

### 例题 5：周期判断

- **方法**：$d(i) = \gcd\{n: P_{ii}^{(n)} > 0\}$。
- **非周期**：$d(i) = 1$。
- **互通类**：同一类中周期相同。
- **特殊情形**：自环（$P_{ii} > 0$）必非周期。

### 例题 6：n 步转移概率计算

- **方法**：$P^{(n)} = P^n$，矩阵幂运算。
- **特征值分解**：若 $P$ 可对角化，$P = Q \Lambda Q^{-1}$，则 $P^n = Q \Lambda^n Q^{-1}$。
- **极限**：对遍历链，$\lim_{n \to \infty} P^n$ 的每行都是极限分布 $\pi$。

|------|------|
| $P(X_{n+1}=j \mid X_n=i, \ldots) = P(X_{n+1}=j \mid X_n=i)$ | 马尔可夫性 |
| $P^{(n)} = P^n$ | n 步转移 = 一步转移的 n 次幂 |
| $P^{(n+m)} = P^{(n)}P^{(m)}$ | C-K 方程 |
| $f_{ii} = 1$ | 常返状态 |
| $\sum_{n} P_{ii}^{(n)} = +\infty$ | 常返等价条件 |

| $\mu_{ii} = +\infty$ | 零常返 |

| $\sum_j \pi_j = 1$ | 归一化 |
| $\lim_{n \to \infty} P_{ij}^{(n)} = \pi_j$ | 遍历链极限分布 |
| $\pi_j = \frac{1}{\mu_{jj}}$ | 稳态分布与平均返回时间 |
